# Data.gov content portal adaptation
Requires Firekylin>=2.17.1. Reimplements historic Data.gov/Roots content portal bands: white masthead, blue intro, gray search strip, native-category browse, light-blue latest article and editorial updates. Configure introTitle/introText/footerText. Homepage first public item occupies the blue highlight once; remaining items appear below with unchanged native pagination. Other routes use blue section headers and plain reading pages. Native search is explicitly “搜索本站文章”.

This is a blog/content portal, not CKAN. No dataset index/counts/download API, harvesting, metrics, maps, events, agency participation, external search/suggestions, Twitter embeds, data stories plugins or government services. No flag, official Data.gov logo, endorsement claims or demo metrics. Native categories use initial-character marks instead of unrelated official sector icons. List metadata shows native author/date; categories/tags remain detail links. Uses locally available Lato with Arial fallback; no remote font dependency. No upstream PHP/JS or LESS build executed.

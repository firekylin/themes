# Strange Case for Firekylin

Strange Case’s fixed bottom-aligned sidebar, original dark-brown/green palette and large post headings.

Source https://github.com/ExchangeRate-API/strange-case; exact revision and authors in NOTICE.md, full MIT license in LICENSE. Includes original Bootstrap 3.3.7 and notices; preserves upstream Hyde/Base16 acknowledgments. Uses native summaries because the index API does not provide full article bodies. Sidebar stays in normal flow on mobile. Default palette is darkbrown; Roboto uses system sans-serif fallback. Demonstration images and contact/social widgets are omitted.

Firekylin 2.17.1+ native posts/pages/attachments, archives, taxonomy, search, pagination, navigation, footer author/text and gated comments are supported. Hugo shortcodes and custom RSS are not ported. Remote Waline authentication/submission is untested. CSS and Eta are editable without a build step.

Actual ZIP installation, desktop/mobile screenshots and reproducible runner: verification/strange-case. Compared pinned upstream templates/CSS, without a live upstream-demo pixel-parity claim.

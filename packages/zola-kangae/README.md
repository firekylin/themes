# Kangae for Firekylin

Source https://github.com/ayushnix/kangae (author also references git.sr.ht/~ayushnix/kangae); exact revision in NOTICE.md. Licensed NCSA, including this adaptation. Full source license and separately attributed HTML5 Boilerplate MIT notice included.

Preserves optional avatar/profile header, compact dated entries, dotted rules, fluid spacing/type and original Modus-inspired automatic light/dark colors. Inline list titles are visually hidden below 48rem as upstream; accessible read-more links retain the article name. Single article titles remain visible at all widths. Native lists supply safe excerpts rather than upstream full article bodies; full content is available on the article page. Native pagination extends the static index.

Supports Firekylin 2.17.1+ posts/pages/attachments, archive/taxonomy/search/pagination, navigation, profileImage/authorName/footerText and gated comments. Zola shortcodes, source/content-license configuration, custom social/GitHub discussion links, image metadata, per-tag feeds and PWA/manifest output are omitted. Remote comment authentication/submission is untested. System fonts; no demo images or scripts bundled.

Actual ZIP/SQLite verification covers 18 desktop/mobile routes, no-JavaScript search/navigation, privacy/comments, wide media, configured avatar and system dark colors. Screenshots compare pinned source CSS/templates, not live-demo pixel parity. Shipped CSS/Eta is directly editable.

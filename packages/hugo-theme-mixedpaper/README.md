# Mixedpaper for Firekylin

WayJam So's MIT Mixedpaper is adapted using the original compiled Sass and local modern-normalize 0.6.0. It retains the blue masthead and rotating site-title link, centered monospace navigation, overlapping white post sheets with teal headings/right-aligned dates, gray/coral footer, compact filtered lists and blue-gray grouped archive headings. Native excerpts are plain text; optional safe featured images use the original summary-image treatment. No demo content or favicon artwork is distributed.

Native Widgets handle posts/pages, archive/taxonomy/search, pagination, protection, comments and attachments. Archive groups use the original yearly presentation with native date labels. Adjacent public article links come from the core's filtered previous/next data. Footer text/author and an optional escaped plain-text article note are configurable. Navigation and back-to-top links work without JavaScript; the floating desktop top link is progressively shown on scroll. Reduced-motion disables header rotation and animation.

Differences: no Hugo RSS/analytics pipeline, Disqus/Valine client, Hugo shortcodes/highlight renderer, custom post-license Markdown or per-section neighbors. Firekylin supplies native comments and global public neighbors; source syntax styles remain available for compatible markup. Detail-title/archive text colors are darkened for readability. No live upstream pixel comparison or remote comment submission is claimed.

Protected listing covers are suppressed for explicit protection flags/hashes and the core’s redacted-title marker, because this core revision can retain featured-image metadata after redaction.

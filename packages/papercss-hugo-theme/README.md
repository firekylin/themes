# PaperCSS for Firekylin

Adapted from Zachary Betz's papercss-hugo-theme, pinned in NOTICE.md. Theme MIT; PaperCSS framework ISC; Normalize7.0.0 MIT; locally hosted Neucha and Patrick Hand SC OFL1.1. All notices and unmodified-font hashes included. Original framework/custom CSS retained in res/source. Served CSS removes the Google Fonts import and replaces the bundled geometry2.png texture, whose source attribution was not established, with plain gray. No demo pictures, favicons or analytics included.

Preserves the paper-sheet container, irregular hand-drawn borders, handwritten typefaces, split navigation and spacious text summary index. Local fonts match upstream families; CJK uses system fallback. Visible wrapping menu replaces the CSS checkbox hamburger. Fixed original light palette is retained under either OS color scheme. Native posts/pages/attachments, taxonomy, archives/search/pagination and comment gating use Firekylin2.17.1. All article body content is preserved; list summaries are escaped. Footer author/text settings are escaped.

Hugo shortcodes, automatic TOC, per-post show_summary, favicon generation, Google Analytics, custom RSS and external Disqus integration are omitted. Native remote comment login/submission unverified. CSS remains usable without JavaScript.

Actual ZIP verification uses Firekylin2.17.1 SQLite across18desktop/mobile routes, no-JS menu/search, private/draft filtering, native media and comment gating. Additional checks cover local font loading, paper container/border and fixed light palette. Source-based visual review, not upstream live-demo pixel matching.

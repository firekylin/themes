# Pulp for Firekylin

Source https://github.com/koirand/pulp; exact revision in NOTICE.md. MIT license, original CSS/avatar-border SVG and GitHub Markdown CSS MIT notice included. System fonts only.

Preserves the centered profile, optional circular avatar/outlined border, quiet gray background, monthly grouped title links, centered metadata and automatic dark reading palette. Native homepage combines profile and monthly blog list instead of a profile-only landing page. Configure `profileImage` with an http(s) or site-absolute URL. Native pagination may split one month across pages, grouping each visible page.

Native Firekylin 2.17.1+ posts/pages/attachments, archives/taxonomies/search/pagination, navigation and gated comments. Native server-side search replaces the jQuery/Lunr static index, without exporting private posts. Font Awesome/social icon menus, custom scripts/metadata, analytics, MathJax and legacy browser polyfills are omitted. No demo avatar or remote dependencies. Remote comment login/submission untested.

Actual ZIP/SQLite verification covers 18 desktop/mobile routes, no-JS navigation/search, privacy/comments, attachments, media, monthly grouping, avatar and system dark colors. Screenshots compare pinned source templates/CSS, not live-demo pixel parity. Source CSS and native Eta are directly editable.

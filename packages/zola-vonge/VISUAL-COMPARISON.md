# Visual adaptation

Pinned blog-card/page-heading/page/header templates and original Sass define the reference: pale-blue background, centered 58px heading, Inter, 16px rounded image cards with overlapping content, gradient tags and split cover/article title. Native metadata/navigation replace Zola data; author portraits and service blocks are omitted. Image-free cards remove negative overlap. Desktop/mobile installed screenshots and reproducible tests are included; no live upstream pixel comparison was performed.

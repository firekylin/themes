# Vonge for Firekylin

The Vonge blog layout from CloudCannon and Pascal Berrang is adapted with original MIT Sass, pale-blue background, Inter typography, rounded three/two/one-column cards, overlapping white content panels, gradient tag badges, author/date metadata and a split article cover/title. Missing or unsafe covers omit images; image-free cards remove the negative overlap. Tags are queried only for current public result IDs. Author portraits are omitted because no verified demo portrait is bundled.

Native posts/pages, archive/taxonomy/search, pagination, attachments, protected content and comments are supported. Navigation wraps visibly without JavaScript; the upstream page-load overlay is disabled. Footer text/author are configurable. Inter is local under OFL, with Chinese system fallbacks.

This migrates Vonge’s blog and article layouts. Bookshop/Zola block editing, portfolio/testimonial sections, newsletter/contact services, sliders, related-post computation, feed generation and social sharing are not implemented. No sample photos, icons, analytics or external services are bundled. No live upstream pixel comparison or remote comment submission was performed.

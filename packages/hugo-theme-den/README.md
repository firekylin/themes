# Den for Firekylin

Port of shaform/hugo-theme-den, originally the Nest Pelican design by Matthieu OLIVIER. Pinned revision in NOTICE.md. Theme and adaptation are GPL-2.0-only; original source CSS, both authors’ notices and licenses, Bootstrap4.1.3 MIT and Open Sans OFL licenses are retained. All fonts/styles are local. No demo images, logos, remote scripts or trackers are included.

Preserves the blue masthead, centered title/description, red underline and links, dated archive rows, 850px white reading column and charcoal footer. Article titles and dates appear in the blue masthead. The archive changes from a 25/75 date/title row to a stacked list on phones. Native menus remain visible and wrap in document flow rather than using the upstream fixed collapsed Bootstrap navbar. The default blue header is retained; optional photographic header/logo are not implemented.

Native Firekylin posts, pages, attachments, archives, taxonomy, search, pagination, protected content and comments are supported. Footer text/author settings are escaped. Multi-author cards, multilingual switching, related-post recommendations, external Disqus, custom galleries/shortcodes, header-image resources and social/link data menus are not ported. Native taxonomy and content remain available. Native remote comment submission/login is untested.

Validation installs the actual ZIP into Firekylin2.17.1 with SQLite and checks18routes at1440/390px, private/draft exclusion, no-JS navigation/search, native attachments/pagination/comments and wide video/audio. Additional assertions verify date rows, hero article title, original palette, local fonts and responsive reading width. Screenshots compared to pinned source CSS/templates, not a live upstream demo.

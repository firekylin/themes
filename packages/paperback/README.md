# Paperback for Firekylin

Paperback’s warm paper background, 34rem serif reading column and spacious expanded post summaries.

Source https://github.com/damiencaselli/paperback, fixed revision and attribution in NOTICE.md. Original MIT license and editable CSS retained. System font fallbacks replace remote fonts; no remote font service or demo assets are bundled. The upstream homepage preview is paginated using native Firekylin pagination instead of a fixed three-post limit.

Requires Firekylin 2.17.1+. Native posts/pages/attachments, archive/taxonomy/search, pagination, navigation, footer author/text options and comment gating. Text-first feed preserves the upstream layout. No demo content, tracking or account credentials bundled. Hugo shortcodes, custom RSS generation and provider-specific comment scripts are not ported; external Waline login/submission untested. Shipped CSS and Eta need no build step.

ZIP installation, desktop/mobile screenshots and verification runner: verification/paperback. No live upstream demo or pixel-parity claim.

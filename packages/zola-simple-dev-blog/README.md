# Simple Dev Blog for Firekylin

Source https://github.com/bennetthardwick/simple-dev-blog-zola-starter; pinned revision/author in NOTICE.md. Full MIT/Normalize licenses and Rubik SIL OFL included, with original Sass and font hashes.

Retains Rubik typography, green underlined links, spacious blog previews, and optional layered animated portrait. Combines the original profile homepage and blog list into one native paginated home. Portrait is hidden below 880px as upstream; reduced-motion disables its animation. Green links are darkened slightly for text contrast. The default light palette is retained; optional upstream dark mode is not exposed.

Supports Firekylin 2.17.1+ posts/pages/attachments, archive/taxonomy/search/pagination, navigation, optional profileImage/authorName/footerText and gated comments. Zola image resizing/icons, project pages, prerender hints, reading-time/word-count, related-post links and analytics are omitted. Remote comment authentication/submission is untested. No upstream photos, external scripts or remote fonts are bundled.

Actual ZIP/SQLite verification covers 18 desktop/mobile routes, no-JavaScript search/navigation, privacy/comments, media containment, portrait configuration/mobile hiding and reduced-motion behavior. Screenshots compared with pinned source templates/Sass; no live-demo pixel parity claim. Shipped CSS/Eta is directly editable.

# Editorial for Firekylin

Editorial’s coral header rule, serif titles, ruled two-column image cards and outlined buttons.

Native migration of https://github.com/TryGhost/Editorial; source revision and author in NOTICE.md, original license in LICENSE. Requires Firekylin 2.17.1+. Uses native site title/description/navigation, authorName/footerText and article featuredImage. Supports posts/pages/media, archives/taxonomy, search, pagination, protected content and comments.

Upstream Sass/CSS is retained with compatibility rules for native templates. Upstream build plugins, commercial features, external fonts/icons, demo photographs, analytics and remote widgets are excluded. Navigation wraps without JavaScript.

Design: HTML5 UP, adapted by Ghost Foundation and this Firekylin port. Original design CC BY 3.0, Ghost adaptation MIT; full terms preserved in LICENSE.

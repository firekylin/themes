# Bootstrap 4 Blog for Firekylin

Bootstrap 4 Blog’s classic blue navigation bar, large blog masthead, serif text column and inset sidebar.

Native migration of https://github.com/alanorth/hugo-theme-bootstrap4-blog; source revision and author in NOTICE.md, original license in LICENSE. Requires Firekylin 2.17.1+. Uses native site title/description/navigation, authorName/footerText and article featuredImage. Supports posts/pages/media, archives/taxonomy, search, pagination, protected content and comments.

Upstream Sass/CSS is retained with compatibility rules for native templates. Upstream build plugins, commercial features, external fonts/icons, demo photographs, analytics and remote widgets are excluded. Navigation wraps without JavaScript.

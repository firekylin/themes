# Anzhiyu for Firekylin
1400px board layout,340px home recommendation region,identity panel and colorful category buttons,latest-post hero with six real recent links,category tab bar,225px covers and double-column article cards above1200px,285px right sidebar,blue author card,500px post hero and native outline. At1200px the header becomes a horizontal recent-post strip; mobile uses200px image cards and450px post header. Configure identity/profile/avatar. Native routes,search,pagination,comments/private-content filtering,dark mode,copy URL,hide sidebar and reveal recommendations.

This is the public blog presentation, not all Anzhiyu plugins: no AI summary, chat, music services, essay/friend-circle/gallery backends, analytics, location claims, fake original/unread labels, PJAX/PWA or image-derived color extraction. Fixed blue header replaces dynamic sampled tone. Six newest public posts replace Hexo custom top_group_list; identity uses simple geometric decoration instead of canvas people/skills. Native links work without JS; noJS desktop latest card covers secondary recommendations (also in article feed). Core comment integration replaces vendor-specific counters; external client submission is not verified. Requires Firekylin>=2.17.1.

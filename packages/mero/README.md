# Mero for Firekylin

Darshan Baral’s MIT Mero personal-blog theme, adapted with original Mero CSS and its Bootstrap 4.3.1 foundation. Preserves the dark canvas, yellow links, locally hosted Overlock/Roboto Mono fonts, outlined panels with floating labels, portrait/About/recent layout and dated article cards.

The first homepage pairs an optional portrait with escaped profile text and the current public post page. All posts remain reachable via native pagination; later pages and taxonomy filters use the standalone list. Unlike upstream’s four-item recent list, the homepage shows the configured Firekylin page size. Missing or unsafe portrait URLs collapse the portrait column. Article covers use native featuredImage with site-relative/HTTP(S) validation. Lists query only current public archive IDs for metadata. Native details disclosures expose list and article metadata with keyboard and without JavaScript; navigation stays visible and wraps rather than using the upstream sections dropdown.

Posts, pages, archives, category/tag/search, password protection, native comments and attachments are supported. Profile title/intro/portrait and footer text/author are configurable. Hugo sections, reading-time estimates, social icons, shortcodes and custom previous/next logic are not reproduced; native archives and pagination remain available. Demo photographs and Font Awesome are omitted. No remote assets or client scripts required.

Verification includes actual installed ZIP/SQLite pages and inspected desktop/mobile screenshots. Live upstream pixel comparison and remote comment submission were not performed.

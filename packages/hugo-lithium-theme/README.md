# Lithium for Firekylin

Lithium’s pale full-width masthead, year-grouped archive, strong sans-serif titles and serif reading column.

Source https://github.com/jrutheiser/hugo-lithium-theme; pinned revision, author and original license in NOTICE.md and LICENSE. The site title replaces the upstream configurable image logo; no demo logo is shipped. Merriweather/Lato use system serif/sans-serif fallbacks. Hugo reading-time labels and Disqus are not reproduced.

Native posts, pages, attachments, archives, categories, tags, search, pagination, navigation and gated comments; requires Firekylin 2.17.1+. Footer author/text settings are supported. Hugo shortcodes and RSS generation are not ported. External Waline authentication/submission is untested. Editable CSS and Eta ship without a build step.

Actual ZIP install and desktop/mobile route tests: verification/hugo-lithium-theme. No live upstream demo comparison or pixel-parity claim.

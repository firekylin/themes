# Terminal
A Firekylin port of panr’s Hugo Terminal, MIT. Requires Firekylin >=2.17.1. Fira Code font uses SIL OFL 1.1.

Preserves the striped logo, double dotted headings, accent-bordered images, monospaced article summaries and left-aligned 864px container. Configure layout as left/center/full and six-digit background, foreground and accent colors. Supports framed intro, native featuredImage covers, mobile menu, heading links, optional TOC (toc=false disables), clipboard code copy, search, pagination, taxonomy and gated native comments.

Static Hugo shortcodes, multi-language content routing, syntax-highlighting engines and adjacent-post navigation are not executed or reproduced. Code remains readable without JS; clipboard controls require browser permission. Waline replaces upstream comment integrations. See NOTICE and visual comparison.

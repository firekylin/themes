# Henry for Firekylin

Henry’s blue top rule, lightweight system typography, date-first post list and wide article column.

Source https://github.com/sirodoht/zola-henry; exact revision and authors in NOTICE.md, full MIT license in LICENSE. Original henry.css preserved, with Normalize notice for its reset rules. Visible wrapping navigation replaces the hover-only mobile dropdown. Metadata/blue link contrast is strengthened. No external fonts, social SVG icons or demo assets bundled; Source Code Pro uses monospace fallback. Custom Zola feeds and template-specific about pages are replaced by native Firekylin routes.

Firekylin 2.17.1+ native posts/pages/attachments, archives, taxonomy, search, pagination, navigation, footer author/text and gated comments are supported. Zola shortcodes and custom feeds are not ported. Remote Waline authentication/submission is untested. Compiled CSS and Eta are editable without a build step.

Actual ZIP installation, desktop/mobile/palette screenshots and reproducible runner: verification/zola-zola-henry. Compared pinned upstream templates/CSS, without a live upstream-demo pixel-parity claim.

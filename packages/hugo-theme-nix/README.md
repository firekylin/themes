# Nix for Firekylin

Nix’s green terminal prompt, dark navigation bar, gray title/date rows and heavy ruled post summaries.

Source https://github.com/LordMathis/hugo-theme-nix, fixed revision and attribution in NOTICE.md. Original MIT license and editable CSS retained. Documented system font fallbacks replace remote font services; third-party icons and scripts are not bundled. Ports the upstream blog-list view. The standalone profile/avatar landing page and multilingual dropdown are not implemented. Native navigation remains visible without Bootstrap JavaScript. Bootstrap 5.0.1 CSS is bundled with its MIT license.

Requires Firekylin 2.17.1+. Native posts/pages/attachments, archive/taxonomy/search, pagination, navigation, footer author/text options and comment gating. No demo content, tracking or account credentials bundled. Hugo shortcodes and custom RSS generation are not ported; external Waline login/submission untested. Shipped CSS and Eta need no build step.

ZIP installation, desktop/mobile screenshots and verification runner: verification/hugo-theme-nix. No live upstream demo or pixel-parity claim.

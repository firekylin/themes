# Bilberry for Firekylin

Bilberry’s dark masthead, vertical timeline bubbles and spacious white article cards.

Native migration of https://github.com/Lednerb/bilberry-hugo-theme; pinned revision and original author in NOTICE.md, complete license in LICENSE. Requires Firekylin 2.17.1+. Site title/description/navigation, authorName/footerText and article featuredImage use native configuration. Posts/pages/media, archives/taxonomy, search, pagination, protected content and comment gating are supported.

Original upstream CSS is retained (Clarity/Jane compiled from Sass with local paths and fonts excluded). Hugo generators, shortcodes, external fonts/icons, demo photographs, analytics and remote widgets are excluded. Uses light appearance and wrapping navigation without JavaScript. No unsupported upstream controls are shown.

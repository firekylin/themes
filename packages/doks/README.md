# Doks for Firekylin
Native landing/blog/documentation layouts based on Doks and doks-core. Requires Firekylin >=2.17.1. Configure introTitle, introText and footerText. Homepage retains centered headline, pill CTA and fading dot field then shows native blog cards. Posts use the centered blog header/cover layout. Native pages use the three-column documentation layout: site navigation/categories/recent public posts at left, page content at center, generated heading TOC at right; mobile sidebars collapse. No invented filesystem chapter hierarchy.

Includes persisted/system light/dark mode, native search, navigation, pagination, privacy and conditional comments. Uses Jost if locally installed, otherwise system sans; no font files bundled. No Hugo/Thulite build, FlexSearch, version/language routing, AI buttons, Markdown downloads, shortcodes, Mermaid/KaTeX/Kroki, code highlighter, edit links or weighted chapter previous/next. Blog excerpts and native data replace Hugo frontmatter. No performance/security score claims copied from demo.

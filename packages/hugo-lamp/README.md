# Lamp for Firekylin

Port of Huy Nguyen’s Hugo Lamp using the original MIT Sass, green 320px sidebar, shadowed summary cards, green article headings and locally bundled Roboto/Roboto Mono fonts. Nuo template and Normalize MIT notices and both font OFL notices are retained.

Firekylin posts/pages, attachments, taxonomy, search, pagination, protected content and comments use native widgets. Optional avatar and post featuredImage use validated HTTP(S) or local URLs. Author/footer text are configurable. The mobile header shows wrapping navigation without JavaScript. Responsive breakpoint is unified at 800px to prevent the original 640–800px grid mismatch.

This is a normal HTML theme, not an AMP implementation. AMP sidebar/state toggle, AMP shortcodes, share icons, ads and analytics are not reproduced. The theme is light-only; no demo photos are bundled. The optional original avatar is configured by the site owner. Remote comment submission is not covered by local validation.

Validation: actual ZIP install on pinned Firekylin 2.17.1, 18 desktop/mobile SQLite routes, category/tag labels, 320px desktop sidebar and stacked 390/700/800px layouts, audio/video containment, protected content, comments, no-JS navigation/search and footer configuration. Screenshots were inspected against source CSS/templates; no live upstream pixel comparison.

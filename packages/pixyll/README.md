# Pixyll for Firekylin
42rem reading column, serif body,large600-weight sans article links,italic gray metadata,thin post dividers,airy header and centered pale footer. Responsive root type14/16/18/20px, native summary lists/routes/search/pagination/comments/privacy. No theme JS required; navigation wraps visibly on small screens. Configure author/footer text.

External Google fonts use system fallbacks. No Jekyll plugins/feed,Formspree contact,analytics,Facebook/Disqus comments or animation packages; core native comments replace upstream integration. Remote comment submission untested. Dates use supported numeric format. Requires Firekylin>=2.17.1.

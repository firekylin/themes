# Hugo Future Imperfect for Firekylin

Original https://github.com/jpescador/hugo-future-imperfect, pinned in NOTICE.md. Julio Pescador’s Hugo adapter is MIT, while the original Future Imperfect design by HTML5 UP is CC BY 3.0. Keep its visible design credit and license link. Original CSS retained, Firekylin changes clearly marked. Local unmodified Raleway and Source Sans3 font files carry separate OFL1.1 notices. No demo media, FontAwesome/Academicons, JS libraries or tracking are bundled.

Preserves the pale-gray canvas, left editorial sidebar, large bordered white article cards with split title/date header, letter-spaced Raleway headings, featured images and outlined reading buttons. Source Sans3 is used as the current Source Sans family release. Native recent-post widget fills the sidebar; native site name/description and footer author/text options are escaped. Sidebar follows articles on mobile; navigation remains visible and wraps without JS. Native featuredImage HTTP(S) or site-absolute URLs are supported, invalid/missing images use text-only cards. Posts/pages/attachments, taxonomies, archive/search/pagination, protected content and native gated comments are supported. Palette stays light under dark OS preference; reduced-motion removes transitions.

Changes: homepage uses a native paginated summary feed instead of the upstream single-latest-post front page. Native search replaces Google site search. Native HTML tables keep all headers/cells visible on mobile instead of relying on the upstream JS table accordion. Slide-out search/share menus, avatar/social configuration, recent thumbnail duplication, custom category counts, Hugo shortcodes/image transforms, MathJax, syntax highlighting JS, static next/previous navigation and Disqus are not ported. Native author/date and tags replace Hugo front matter. Remote comment authentication/submission is not verified. No desktop sticky header, to preserve access with long navigation.

Verification uses an actual packaged ZIP installed into Firekylin with disposable SQLite, desktop1440/mobile390 routes, private/draft filtering, comments, no-JS search/navigation, native media, featured-image fallbacks, sidebar layout, local fonts, visible design credit and footer-author override. Screenshots demonstrate the adapted layout, not live-demo pixel equality.

# Learn for Firekylin
Ports Hugo Learn's purple documentation style:300px fixed charcoal sidebar, purple search masthead, cyan links, thin uppercase chapter titles, generous48/96px reading padding, dark code blocks and top breadcrumb bar. Requires Firekylin>=2.17.1. Configure introTitle/introText/footerText. Native navigation/categories/recent public posts replace Hugo weighted chapter tree; expandable sidebar groups remain. Browser-local visited markers can be cleared; no remote tracking. Visible-heading TOC expands inline. Native search submits to Firekylin rather than Lunr instant search.

Native post/page/attachment/archive/taxonomy/search/pagination/privacy and conditional comments supported. Mobile uses in-flow collapsible navigation rather than translating whole viewport230px. Work Sans/Novecento use installed fonts with Helvetica/Arial fallback; no unverified font files bundled. No Hugo shortcode processing, Mermaid,language selector,GitHub edit links,chapter previous/next ordering,attachments discovery,Lunr index or clipboard plugin. Blog list is native adaptation; not a documentation filesystem or authoring backend.

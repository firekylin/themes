# Hugo Cards for Firekylin

Source https://github.com/bul-ikana/hugo-cards, derived from https://github.com/sharu725/cards. Exact upstream revision and attribution in NOTICE.md; original theme, Webjeda, Bootstrap, Bootswatch and Normalize MIT licenses included. Local unmodified Raleway font includes SIL OFL license.

Retains original Sass/Bootswatch Readable styling, three-column image panels with layered hover shadows, title/date/summary cards and the article recent-post sidebar. Whole cards remain links. Native featuredImage replaces Hugo bundled images; missing/invalid images leave a text card instead of an unlicensed demo default. Sidebar recent posts use the native public-post widget. Desktop full titles replace upstream 25-character truncation. Native wrapping navigation replaces the JavaScript burger/dropdown.

Supports Firekylin 2.17.1+ posts/pages/attachments, archives/categories/tags/search/pagination, configured navigation, authorName/footerText and gated comments. Profile-sidebar variant, Hugo image processing, Facebook boxes, analytics, Disqus-specific setup and previous/next article links are omitted. Remote comment authentication/submission is not tested. This is the light theme; no external font/script service dependencies.

Verification uses an actual installed ZIP/SQLite site with 18 desktop/mobile routes, no-JavaScript navigation/search, privacy/comments, native recent-post sidebar, safe images and responsive media. Screenshots compared with pinned source templates/Sass, not live-demo pixel parity. Shipped CSS/Eta is directly editable.

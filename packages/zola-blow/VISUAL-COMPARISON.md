# Visual adaptation

Pinned templates/index.html, section.html, page.html and original generated CSS are the reference: centered round portrait, gray rounded shadowed cards, dark gray alternate canvas, underlined prose headings and gray navigation. Native index combines intro/section; date metadata replaces unavailable static reading estimates. Text controls replace SVGs, and collapsible heading contents replaces Zola’s precomputed tree. Desktop/mobile screenshots and reproducible installed-site checks are in verification/zola-blow. No live upstream pixel comparison was performed.

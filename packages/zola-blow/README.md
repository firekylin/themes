# Blow for Firekylin

Thomas Chartron’s MIT Zola Blow port retains the original compiled Tailwind stylesheet, gray navigation, centered optional portrait/introduction, rounded shadowed gray article cards and light/dark palettes. Native homepage combines the upstream personal intro and blog section so pagination stays directly usable. Dates replace Zola reading-time/word-count metadata. Cards mildly enlarge on desktop hover; reduced-motion and mobile layouts disable that effect.

Optional avatarUrl accepts http(s) or site-absolute URLs; profileName/introduction and footer text/author are configurable. A persistent text button replaces icon theme controls. No-JS defaults to readable light colors and visible navigation. Post/page headings get a DOM-safe collapsible h2/h3 contents list; no headings means no empty TOC. Article contents and native attachments, search, taxonomy, pagination, protected posts and comments are supported.

Zola multilingual switching, arbitrary sliding sidebar, social SVG icons, Elasticlunr index, reading estimates, syntax themes, ads and analytics are omitted. No remote assets or example portrait are bundled. No live upstream pixel comparison or remote comment submission was performed.

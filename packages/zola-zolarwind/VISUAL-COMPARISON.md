# Visual adaptation

Pinned list/list-element/blog-post/header templates and generated Tailwind CSS are the reference: 3/2/1-column cards with 192px covers, warm-neutral palette, blue links, metadata under summaries, sticky desktop header and full-width article banner. Native links replace SVG icons; mobile navigation stays expanded and no default photo is bundled. Installed screenshots and reproducible tests are in verification/zola-zolarwind; no live upstream pixel comparison was performed.

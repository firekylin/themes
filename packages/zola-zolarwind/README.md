# Zolarwind for Firekylin

Thomas Weitzel’s MIT Zolarwind blog layout is adapted using its original Tailwind 4.3.3 generated CSS, warm-neutral light/dark palette, blue links, sticky desktop header, 3/2/1-column image cards, 192px article banners and centered footer. Use a post’s featuredImage for covers; missing or unsafe image URLs omit the image instead of bundling demo photography. Current public-result IDs bound tag lookups. Images and title links remain separate from tag controls.

Native posts/pages, archive/taxonomy/search, pagination, protected content, comments and attachments are supported. A persistent light/dark toggle and safe DOM-generated collapsible article TOC are included. Navigation wraps and stays visible without JavaScript; no-JS uses light mode. Footer text/author are configurable.

Native blog routes replace Zola sections. Series navigation, localized resources, reading-time counts, syntax engines, math/diagram shortcodes, Artalk integration and feeds are not implemented. No remote fonts, default banner, icons or service scripts are bundled. No live upstream pixel comparison or remote comment submission is claimed.

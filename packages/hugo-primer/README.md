# Hugo-Primer for Firekylin

Adapted from https://github.com/qqhann/hugo-primer at the revision in NOTICE.md. MIT license and GitHub Primer/Normalize notices retained. Original Primer bundle and theme CSS are shipped as editable source.

Preserves the GitHub-style navigation, original list card component, Markdown typography, 230px sticky taxonomy/TOC sidebar and narrow-screen layout. Uses the upstream card list on the home feed as well as filtered lists. Sidebar categories/tags come from native Widgets. Heading links are generated locally from actual h2–h4 content using DOM text, preserving existing IDs and avoiding ID collisions; original sidebar hides below 1012px. Without JavaScript articles and native navigation/search remain available, but generated TOC is absent.

Supports Firekylin 2.17.1+ posts/pages/attachments, archives, search, taxonomy, pagination, navigation, footer author/text and gated comments. Remote MathJax, social share widgets, Hugo shortcodes and dropdown submenus are omitted. Remote Waline authentication/submission is untested; no upstream demo assets or external fonts/scripts are bundled.

Actual ZIP/SQLite desktop/mobile checks, heading navigation, screenshots, privacy/comment gating and native media containment are in verification/hugo-primer. Compared against pinned upstream CSS/templates, not a live-demo pixel-parity claim. No build step required for shipped CSS/Eta.

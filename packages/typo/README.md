# Typo for Firekylin

Native port of Francesco Tomaselli’s Typo: serif reading, large header title, slash-prefixed monospace navigation, aligned date/title summaries, restrained monochrome palette and article TOC. Original reset/variables/utilities/syntax/main/default-color CSS retained, including its modern CSS light-dark() palette.

Requires Firekylin 2.17.1+ and a modern browser supporting CSS nesting/light-dark(). Native appearance control follows system and persists selection; article headings get real TOC anchors. Uses native title/description/menu/footer options and all core feeds, archives, taxonomy/search, pagination, protected content, attachment media and comments.

Literata/Monaspace use declared local fallbacks; external font binaries excluded. Hugo collections, social SVG icons, Mermaid/math, generated OpenGraph, Giscus, shortcode plugins, automatic reading-time and previous/next ranking are omitted. No demo media or upstream runtime. Remote comment submission untested. MIT source attribution retained.

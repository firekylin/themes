# Simplicity for Firekylin

Adapted from https://github.com/eshlox/simplicity. Exact source revision and author in NOTICE.md; full MIT and dependency licenses retained.

Keeps the original pale navigation, personal introduction/avatar, chronological year groups, Milligram typography, centered article headings and blue-rule code blocks. Homepage combines the original identity view with the blog list so posts are directly discoverable. Optional profileImage uses an explicit local/http(s) URL instead of Gravatar; authorName and footerText are configurable. System fonts replace the remote Roboto request. Sticky wrapping navigation replaces Headroom's animated fixed-height bar.

Native Firekylin 2.17.1+ posts, pages, attachments, archives, categories, tags, search, pagination and gated comments are supported. Year groups reflect the current native paginated result. Hugo shortcodes, language switches, gallery lightboxes, analytics, ads and Disqus are not ported. Remote Waline login/submission and media playback are not tested.

Original Sass is retained in res/source/styles; shipped CSS is editable directly. Actual ZIP/SQLite desktop/mobile and system-dark-light-canvas checks, screenshots and runner are in verification/simplicity. Comparison is against pinned upstream templates/CSS; no live demo pixel-parity claim.

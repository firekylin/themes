# ReFresh for Firekylin

Roberto Jordaney's MIT ReFresh is adapted with its original Bulma 0.7.5/Fresh Sass and refresh.css. It preserves the white/orange palette, split introductory hero, orange section divider, framed image-summary cards with read-more buttons, dark footer and dark tag sidebar. Native cards use 3/2/1 columns; safe user covers crop to the original 3:2 frame, while missing or unsafe images are omitted without a default photo. The original heading font Open Sans is bundled with OFL.

The first home page shows the optional configured hero followed by Firekylin's feed; later/filtered pages open directly on the list. The tag sidebar uses native public tag names/counts and a keyboard-accessible modal dialog with focus containment and Escape dismissal. Without JavaScript a native details list exposes the same tags, and main navigation always wraps visibly.

Posts/pages, archives, taxonomy/search, pagination, protected content, comments and attachments use Firekylin Widgets. Theme settings include plain-text hero title/description, an optional HTTP(S)/site-relative hero image, footer text and author. User input is escaped.

Differences: no Hugo language switcher, arbitrary section tree, shortcodes, nested sidebar, service statistics, resource image processing, highlight/MathJax/Devicon engines, animated SVG menu/loader, cloned navbar or automatic modification-date text. Native controls replace jQuery and icon dependencies; article text remains left-aligned and semantic. Native action text is darkened and footer links lightened for readability, retaining the original turquoise button backgrounds. The home feed is added beneath the original landing layout. No live upstream pixel comparison or remote comment submission is claimed.

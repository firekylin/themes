# Aurora for Firekylin
Native Firekylin>=2.17.1 adaptation of Auroral-UI/Benny Guo's Aurora. Preserves cyan/violet/pink gradients, rounded fading-cover cards, large lead article, category tab strip, bordered profile sidebar and full-width article heading above the reading columns. Dark default plus persistent light switch. Configure avatarUrl/profileName/profileBio; explicit post options.featuredImage supplies covers. Default geometric mark is original CSS, not the demo author's logo.

Uses upstream non-feature/latest-horizontal-article preset: first public article of home page1 becomes the lead without duplication or changing pagination. Remaining articles use responsive3/2/1 grid. Native article/page/attachment/archive/category/tag/search, privacy and conditional comments. Native category links replace SPA filters. List labels say “文章” rather than inventing per-post categories; actual categories/tags appear on detail. Recent native posts replace remote recent-comments widget.

Not a Vue SPA port: no Hexo JSON API/router transitions, language switching, notification system, Hexo custom containers, Gitalk APIs, music player, virtual assistant, PWA cache, automatic metrics/views/reading duration or featured-selection carousel. Core Markdown/HTML and configured Firekylin comments render normally. TOC derived from visible headings. Sidebar hidden below1024px. No demo author identity, artwork, stats or remote services included.

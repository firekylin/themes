# Base16 for Firekylin

Base16 Eighties terminal palette, bracketed prompt masthead and contrasting editorial summary panels.

Source https://github.com/htdvisser/hugo-base16-theme, fixed revision in NOTICE.md. Original editable CSS and MIT license retained. Source Code Pro uses the upstream monospace fallback; no external fonts are downloaded. Base16 Eighties palette attribution to Chris Kempson is retained in the CSS. The upstream demo hero logo and placeholder instructions are replaced with the configured site title.

Firekylin 2.17.1+: native posts/pages/attachments, search, taxonomy, archive, pagination, comments gating, site navigation and footer author/text options. No demo images, third-party analytics or remote comment scripts bundled. Text-first index retains upstream structure. Native Eta/CSS source requires no build step.

Hugo shortcodes, custom RSS generation and multilingual navigation are not implemented. Firekylin comments replace external integrations; Waline remote login/submission untested. Yinyang gallery shortcodes/related-post widgets are not ported. No live upstream demo/pixel-parity claim. Real ZIP-installation screenshots and verification runner under verification/base16.

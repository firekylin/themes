# Minimo for Firekylin

Source https://github.com/MunifTanjim/minimo; exact pinned revision in NOTICE.md. Full original MIT license and Normalize notice are retained.

Preserves the 300px author sidebar, 740px maximum reading containers, yellow separators, compact date/title list rows, system typography and per-post covers. The sidebar contains real site description, native search and tag data. Native details/summary replaces the JavaScript off-canvas drawer: expanded on desktop, initially collapsed on mobile with JavaScript, available expanded without JavaScript. Wrapping native navigation remains accessible separately.

Supports Firekylin 2.17.1+ posts/pages/attachments, native protected content, archives, taxonomies, search, pagination, navigation, author/footer configuration and gated comments. Hugo widgets, shortcodes, multilingual/RTL configuration, table-of-contents generation, Staticman/Isso/Disqus and analytics are not ported. Native comments replace upstream service integrations; remote Waline authentication/submission is untested.

Original Sass is in res/source/stylesheets; editable compiled CSS is shipped without a build dependency. Actual ZIP/SQLite desktop/mobile routes, sidebar controls, wide media checks and screenshots are recorded in verification/minimo. Comparison uses pinned upstream templates/CSS, not a live-demo pixel-parity claim.

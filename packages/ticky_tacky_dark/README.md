# Ticky Tacky Dark for Firekylin

A native port of kc0bfv’s Hugo theme: original black 1024px canvas, rounded square photo links in two columns, pale blue right navigation, rounded optional header image and image-led detail layout. Original Bootstrap 4.0.0, theme CSS and Open Sans regular are bundled with their notices. Header image/title and footer text/author are configurable. The optional Ubuntu Titling display font is omitted because its source/license provenance is incomplete; headings use Open Sans/system fonts instead.

The source lists site pages ordered by Hugo weight. This port uses Firekylin’s paginated chronological article feed; each featured image becomes its square tile. Missing or unsafe images produce a text tile. Posts/pages use the featured image beside the content when space permits; it stacks on smaller screens. Archive, category/tag headings, search, protected body, comment gating and attachment download/media remain native. Navigation is visible and keyboard-accessible without JavaScript.

Random image lists, per-page buttonimage/imagealt/weight/actualurl redirects, Hugo shortcodes, search-engine verification, RSS generation and analytics are not implemented. Header supports one image rather than random selection; title links and native navigation replace Hugo page menus. No demonstration photos are included. Native comments replace external services; remote comment submission has not been tested.

Verification includes installed ZIP tests on Firekylin 2.17.1, desktop/mobile screenshots and theme-specific geometry/image/navigation assertions. No live upstream pixel-parity comparison is claimed.

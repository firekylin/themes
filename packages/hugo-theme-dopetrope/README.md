# Dopetrope for Firekylin

Native adaptation of Curtis Timson’s Hugo port of AJ / HTML5 UP Dopetrope. Retains original CSS/Sass, centered heavy masthead, italic navigation/date captions, two-column white blog cards with full-bleed covers, red buttons, pale gray canvas, full-width white article and dark recent-post footer. Source Sans 3 is bundled under OFL as the maintained successor to remotely loaded Source Sans Pro. Theme/adaptation CC-BY-3.0; complete licenses and attribution included.

Native posts/pages, pagination, categories/tags/search/archives, attachments, comments and protected posts work through Firekylin widgets. Native featuredImage covers accept site-relative/HTTP(S) URLs and are suppressed for protected listings. Footer author/text are configurable. No JavaScript is required for navigation or search.

This migration targets upstream blog mode. Portfolio projects, icon feature panels, promotional landing banner, left/right sidebars, arbitrary footer blocks, Hugo shortcodes, dropdown menus and Disqus count integration are not implemented. Native public recent posts and archive link replace static footer news/about links. No demo photos, unknown textures, icon fonts or upstream JavaScript are bundled. No live upstream pixel comparison or remote comment submission is claimed.

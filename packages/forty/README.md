# Forty for Firekylin

Forty by AJ / HTML5 UP, Hugo port MarcusVirg, adapted under CC BY 3.0. Original navy palette, large ruled hero, six-color translucent tiles, alternating 40/60 widths, 50/50 tablet grid and single-column phone layout retained. Native published posts populate the original showcase tiles, with date and summary, instead of requiring a hard-coded project list. Article pages retain the original wide reading container, title rule and optional image.

Native categories/tags/archive/search, pagination, password protection, comments and attachments are supported. Featured images accept local or HTTP(S) URLs and are omitted for redacted protected posts. Footer author/text configurable. Source Sans 3 is bundled locally under OFL as the maintained successor of Source Sans Pro.

Navigation remains visible and wraps without JavaScript instead of the original animated overlay menu. Hugo landing-page showcase configuration, spotlight section collection, contact form/Formspree, social icons, Disqus, old IE support and transition effects are omitted. No default/demo photographs or FontAwesome files are bundled; the banner uses the original navy color, and post images come from user content. This is a blog adaptation, not a reproduction of the business/contact landing page. Required attribution remains visible in the footer.

Validation installs the packaged ZIP into Firekylin 2.17.1 and checks 27 routes at 1440/700/390px, tile geometry, page containment, rich text/media, native features and protected metadata/network exclusion. Screenshots are compared with pinned source templates/CSS and upstream repository screenshot; no remote comment submission or pixel-identical demo claim.

# Bare for Firekylin

Port of Tom Forbes’s orf/bare-hugo-theme; revision in NOTICE.md. Retains original MIT notice including placeholder copyright. Original Sass and exact pinned Bulma0.9.4 submodule Sass sources are included, alongside Bulma and embedded Minireset MIT notices. Rebuild command in NOTICE.md. Uses original system font stack; no remote fonts or JavaScript.

Preserves full-width blue info hero, responsive wide Bulma container, compact title/date feed, article title/date/tag hero,20pxarticle typography and pale centered footer. Home hero uses configured author (site-title fallback) and site description. Unlike upstream’s hidden mobile navbar, native text menus remain visible and wrap without JS. Gravatar and Material Design social icons are omitted; no default portrait substituted.

Supports native Firekylin posts/pages,attachments,archives,taxonomy,search,pagination,protected content and comments. Header uses native navigation instead of taxonomy-only links. Footer text/author settings escaped. Optional hero color configuration,PostCSS pruning,Git modification metadata,repo/email/social links,syntax.css and analytics are not ported. Remote comment login/submission remains untested. Light-only original palette retained.

Actual ZIP installation on pinned Firekylin2.17.1 SQLite checks18routes at1440/390px with native media/attachments,long code,private/draft exclusion,comments and no-JS navigation/search. Additional checks coveroriginalbluehero,1344pxdesktopcontainer,compactdatedfeed,articlehero+tags,20pxprose,systemfonts and configuredauthor.

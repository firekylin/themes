# Apollo for Firekylin

Source https://github.com/not-matthias/apollo; pinned revision in NOTICE.md, full MIT license in LICENSE. Original Sass is included. Uses the theme's Space Grotesk font profile (not Zed fonts), with unmodified Space Grotesk and JetBrains Mono files and separate OFL notices/checksums.

Preserves coral link/heading accents, monospaced date column, chronological summary feed, native light/dark colors and wide-screen heading sidebar. Colors follow system until manually selected; selection persists and storage failures are tolerated. No-JavaScript CSS follows the system palette. Local DOM-based h2–h4 links preserve existing IDs and avoid generating collisions. A text control replaces the theme icon.

Native Firekylin 2.17.1+ posts/pages/attachments, archive/taxonomy/search/pagination, navigation, footer author/text and gated comments are supported. Zola cards/talks/character layouts, custom shortcodes, MathJax/Mermaid, analytics, social icons, fancy-code copy controls and static search are omitted. Remote Waline authentication/submission and media playback are not tested. No external font/script dependencies or demo media bundled.

Verification: actual ZIP/SQLite desktop/mobile routes, local fonts, palette persistence, heading navigation, privacy/comments and wide-media containment, with screenshots under verification/zola-apollo. Compared pinned templates/CSS; no live-demo pixel-parity claim. Shipped CSS/Eta is editable directly.

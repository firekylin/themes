# Minos for Firekylin

Minos’s centered serif article feed, fine dividers, compact metadata and original article-entry typography.

Adapted from https://github.com/carsonip/hugo-theme-minos; source revision and author in NOTICE.md, complete upstream license in LICENSE. Requires Firekylin 2.17.1+. Uses native site title/description/navigation, authorName/footerText and article featuredImage. Includes posts/pages/media, search, archives, taxonomy, pagination, protected content and comments.

Upstream engine-specific membership, newsletter delivery, remote search/indexing, analytics, automatic related articles and share integrations are excluded. Local fallback fonts replace upstream remote fonts/icons. No demo photos are redistributed. Responsive navigation/search work without JS.

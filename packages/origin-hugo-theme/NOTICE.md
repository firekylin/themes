Retained original SCSS and compiled CSS. The bundled Eric Meyer reset v2.0 is public domain, as stated in style.scss. Named font stacks use locally installed fonts; no font files are included. Upstream SVG icons, demo photographs, social-service widgets and JavaScript overlays are omitted. Text links and a continuously visible wrapping navigation replace icons and hover-only/JavaScript menus.

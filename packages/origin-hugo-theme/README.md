# Origin for Firekylin

A native adaptation of Andrey Parfenov’s MIT Origin Hugo theme. The original Sass defines its peach background, black offset header frame, asymmetric three-post featured grid, image/text list cards with hard shadows, yellow taxonomy headings and narrow article column. Original source Sass and compiled CSS are retained.

The homepage optionally features its first three public posts (first page only), with remaining posts shown exactly once in the normal list. Cover images use Firekylin featuredImage and only site-relative or HTTP(S) URLs; missing covers stay as text cards. Current-page tag relations are queried only for the public archive IDs. Posts, pages, archives, category/tag/search routes, pagination, password protection, comments and attachments use native Firekylin behavior.

The navigation wraps and stays visible without JavaScript, replacing upstream hover/overlay menus. No JavaScript, remote fonts, default images, icon libraries or service scripts are required. Original font stacks fall back to installed system fonts. Footer author/text and featured mode are configurable. Hugo nested menus, shortcodes, social integrations and theme-specific syntax highlighting are not included; supplied post HTML is rendered by Firekylin. Tables retain semantic columns on mobile rather than upstream’s unlabeled stacked-table conversion. Motion is disabled for reduced-motion users.

Verification includes installed ZIP/SQLite routes at desktop/mobile sizes and inspected screenshots. A live upstream pixel comparison and remote comment submission were not performed.

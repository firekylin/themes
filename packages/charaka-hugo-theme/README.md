# Charaka for Firekylin

Source https://github.com/natarajmb/charaka-hugo-theme; exact revision and attribution in NOTICE.md. Includes MIT licenses for theme/Bulma 1.0.3, original compiled CSS/Sass, and unmodified Domine font with SIL OFL license.

Retains cream paper colors, burgundy links, brown serif headings, year-grouped posts with date/title columns and desktop summaries hidden on mobile. Domine is served locally instead of relying on installed fonts. Native text navigation replaces the upstream social icon bar. The upstream light theme is explicitly pinned, including when the OS is dark. Pagination groups entries within each native result page.

Supports Firekylin 2.17.1+ posts/pages/attachments, archives/categories/tags/search/pagination, configured navigation, authorName/footerText and gated comments. Hugo shortcodes, Gist embeds, client syntax highlighting, jQuery social sharing and Disqus-specific configuration are omitted; native content/comments replace those services. Remote comment authentication/submission is not tested. No third-party remote scripts or demo assets included.

Verification in verification/charaka-hugo-theme installs a real ZIP into SQLite and checks desktop/mobile routes, no-JavaScript navigation/search, privacy/comments, wide video/audio, year grouping, local font and mobile summary visibility. Screenshots compared to pinned source templates/CSS; no live-demo pixel-parity claim. Shipped CSS/Eta is directly editable.

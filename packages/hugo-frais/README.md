# Frais for Firekylin

Frais’s cream masthead, red/blue-gray alternating serif/sans headings and broad editorial summary column.

Source https://github.com/the2ne/hugo-frais; exact revision and authors in NOTICE.md, full MIT license in LICENSE. Original style.css, system-font stacks and Normalize 4.1.1 notice retained. Native wrapping navigation replaces the checkbox menu. Inline code remains inline; code blocks retain the red rule. Native site-wide pagination replaces the original hardcoded three-post feed. No third-party fonts, icon assets, demonstration content or external scripts are included.

Firekylin 2.17.1+ native posts/pages/attachments, archives, taxonomy, search, pagination, navigation, footer author/text and gated comments are supported. Hugo shortcodes and custom feeds are not ported. Remote Waline authentication/submission is untested. CSS and Eta are editable without a build step.

Actual ZIP installation, desktop/mobile/system-dark screenshots and reproducible runner: verification/hugo-frais. Compared pinned upstream templates/CSS, without a live upstream-demo pixel-parity claim.

# BearSimple for Firekylin
BearSimple2.9.9 reading/blog layout: alternating half-image200px cards,75/25 content/sidebar,38px serif identity,80px profile portrait over100px cover,10px sidebar cards, gradient article-title underline. Picture(default) or simple text list via listMode. Featured images are administrator-owned; absent image uses neutral CSS, not upstream demo photography. Mobile150px top covers and hidden sidebar.

Native search, archives, taxonomy, pagination, privacy and comments. Persistent dark mode, local serif/sans reading fonts and three text sizes, distraction-free reading with Escape exit, heading TOC/copy URL, scroll progress and local-calendar remaining-time bars. External named font files are not bundled; installed font fallbacks only. No BsCore dependency or imitation of unsupported user center, registration/submissions, private-comment backend, likes/views, AI, payment, poster generation, gallery plugins, notifications or infinite loading. Native pagination replaces infinite scroll. Do not claim these original plugin capabilities are migrated. Requires Firekylin>=2.17.1.

# Ghazal for Firekylin

A native adaptation of Darshan Baral's MIT Ghazal theme. It retains the original deep-gray/pink palette, 960px reading column, centered full-height introduction with optional circular portrait, dashed article list, generous headings and three-column footer. Original CSS is retained and the matching Open Sans/Fira Code fonts are local with OFL notices. No demo image is included.

The first home page introduces the site, then shows the actual Firekylin feed below. Later pages and taxonomy listings go directly to the article list. Firekylin navigation replaces Hugo sections; a native modal menu provides focus trapping and Escape dismissal, while a wrapping navigation remains available without JavaScript. Left/right arrows follow native list pagination, except while editing, interacting with controls/media, or when the menu is open. Missing previous/next links do nothing.

Native posts/pages, archives, categories/tags/search, pagination, protected content, comments and attachments are supported. The footer uses native public recent-post data. Configure footer text/author, optional avatar URL and plain-text introduction in the theme settings.

Differences: no separate Hugo section landing pages, CV/publication metadata, custom social/share icon services, per-section previous/next article navigation, scroll-hiding header or automatic share links. The header stays accessible. Keyboard arrows are for list pagination; native multi-page article content remains controlled by Firekylin. A home feed is added beneath the original introduction so content is discoverable. No live upstream pixel comparison or remote comment submission is claimed.

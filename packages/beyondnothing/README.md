# Beyond Nothing for Firekylin

Beyond Nothing’s pale gray canvas, compact 650px title/date list and yellow highlighted links.

Source https://github.com/salcan/BeyondNothing; exact revision and authors in NOTICE.md, full MIT license in LICENSE. Original Skeleton 2.0.4, Normalize and custom.css included with separate notices. Replaces hardcoded placeholder site title, email and copyright year with real site identity/navigation/footer settings. Open Sans uses system sans-serif fallback. Hugo word counts and adjacent-post queries are omitted; no demonstration content or external scripts are included.

Firekylin 2.17.1+ native posts/pages/attachments, archives, taxonomy, search, pagination, navigation, footer author/text and gated comments are supported. Hugo shortcodes and custom RSS are not ported. Remote Waline authentication/submission is untested. CSS and Eta are editable without a build step.

Actual ZIP installation, desktop/mobile/system-dark screenshots and reproducible runner: verification/beyondnothing. Compared pinned upstream templates/CSS, without a live upstream-demo pixel-parity claim.

# Whiteglass for Firekylin
800px total wrapper with30px padding,26px serif site name,42px headlines(36px mobile),long native summaries,60px journal spacing,4px dividers and gray continue buttons. Native routes,taxonomies,archive,search,pagination,privacy/comments; no theme JS. Footer metadata configurable.

Georgia replaces externally hosted Bitter. Native summary limits replace Jekyll excerpt separators and no external-url/i18n/feed plugins. Core comment adapter only; external submission untested. Numeric dates. Requires Firekylin>=2.17.1.

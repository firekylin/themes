# Ramium for Firekylin

Port of Rafed Muhammad Yasir’s MIT Ramium using its original CSS and Bulma 0.8.2. Preserves dark navigation, centered title/description, rounded tag chips, rectangular category chips, narrow article list, dates, optional featured images, excerpts and right-aligned reading links. Native categories replace Hugo sections; all tags/categories are shown deterministically instead of random sampling. The home list uses native pagination rather than five fixed posts.

Native posts, pages, attachment downloads, archive/taxonomy/search, pagination, private content and comments are supported. Footer author and text are configurable. Mobile navigation remains visible without JavaScript. Bulma’s audio height is overridden to keep native audio controls usable.

Google search, statistics/admin summary page, nested tutorial sections, reading estimates, social sharing/icons, math and chord processing are omitted. Firekylin native search and administration remain available. No demo media or remote libraries are bundled. Live upstream pixel comparison and remote comment submission are untested.

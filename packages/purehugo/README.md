# Purehugo for Firekylin

Purehugo’s fixed slate sidebar, right-aligned site identity, dated separators and spacious post column.

Source https://github.com/dplesca/purehugo; exact revision and authors in NOTICE.md, full MIT license in LICENSE. Original blog.css retained; Pure percentage-grid classes are converted to equivalent native CSS, so no Pure runtime dependency is required. Pure/Yahoo and Normalize notices retained for the source layout. Full-body feed becomes native excerpts because index rows do not contain full article bodies. Oxygen/Source Sans Pro use system fallbacks; external icon fonts, social share counters and analytics are omitted.

Firekylin 2.17.1+ native posts/pages/attachments, archives, taxonomy, search, pagination, navigation, footer author/text and gated comments are supported. Hugo shortcodes and custom RSS are not ported. Remote Waline authentication/submission is untested. CSS and Eta are editable without a build step. This is a light theme, including when the operating system prefers dark mode.

Actual ZIP installation, desktop/mobile/system-dark screenshots and reproducible runner: verification/purehugo. Compared pinned upstream templates/CSS, without a live upstream-demo pixel-parity claim.

Blue body links are darkened for text contrast.

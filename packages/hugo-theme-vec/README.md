# Vec for Firekylin

Vec’s dark shell-path navigation, month-grouped archive list and narrow minimalist reading column.

Source https://github.com/IvanChou/hugo-theme-vec, fixed revision and attribution in NOTICE.md. Original MIT license and editable CSS retained. Documented system font fallbacks replace remote font services; third-party icons and scripts are not bundled. Ports the original blog-list view rather than its avatar-only profile landing. Optional avatar/social accounts are not invented. The standalone third-party syntax-highlighter CSS is excluded; native article code remains readable.

Requires Firekylin 2.17.1+. Native posts/pages/attachments, archive/taxonomy/search, pagination, navigation, footer author/text options and comment gating. No demo content, tracking or account credentials bundled. Hugo shortcodes and custom RSS generation are not ported; external Waline login/submission untested. Shipped CSS and Eta need no build step.

ZIP installation, desktop/mobile screenshots and verification runner: verification/hugo-theme-vec. No live upstream demo or pixel-parity claim.

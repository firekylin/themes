# Er for Firekylin

Er’s brown site badge, 650px reading column, compact dated post list and Tachyons typography.

Source https://github.com/lingxz/er; exact revision and authors in NOTICE.md, full MIT license in LICENSE. Original Tachyons 4.9.0 CSS is bundled with its MIT and Normalize notices. Source Sans Pro uses system sans-serif fallback. Hugo-generated floating TOC, tag cloud, series and adjacent-post queries are omitted; native category/tag directories and article metadata remain available. No demonstration image, external font or analytics is included.

Firekylin 2.17.1+ native posts/pages/attachments, archives, taxonomy, search, pagination, navigation, footer author/text and gated comments are supported. Hugo shortcodes and custom RSS are not ported. Remote Waline authentication/submission is untested. CSS and Eta are editable without a build step. This is a light theme, including when the operating system prefers dark mode.

Actual ZIP installation, desktop/mobile/system-dark screenshots and reproducible runner: verification/er. Compared pinned upstream templates/CSS, without a live upstream-demo pixel-parity claim.

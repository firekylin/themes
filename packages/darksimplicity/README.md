# Dark Simplicity for Firekylin

Port of Matt Rhone’s Dark Simplicity with original compiled CSS, charcoal canvas, fluid Lora title/summary typography, navigation above a wide masthead and unboxed summary feed. Lora normal/italic fonts are local with OFL notice; the upstream MIT license, including John Otander’s copyright, is preserved verbatim.

Native posts/pages, attachments, taxonomy, search, pagination, private content and comments are supported. Footer author and description are configurable. Dark-only rendering follows the source; muted text is lightened from #676767 to #aaa for legibility. Mobile navigation wraps without JavaScript and the tagline stacks. Original negative tag margin is removed to avoid overlap. Current source templates place tags before summaries; an older upstream screenshot has a right-hand tag arrangement that is not in the pinned CSS. We follow the pinned templates.

Hugo mainSections, schema extensions, Google Analytics and Disqus integration are not replicated; Firekylin supplies comments. No demo assets or flowtype script are copied. The migration uses source CSS/templates and the supplied upstream screenshot as references, not live pixel comparison. Remote comment submission is untested.

# Console for Firekylin

Port of Marcin Mierzejewski’s Console blog layout, including its Terminal CSS 0.7.4 foundation: monospace prompt masthead and blinking cursor, blue links, dated feed, dotted heading rules and automatic system dark palette. Original CSS retained with native integration. Native date labels remain visible on phones, unlike upstream’s hidden dates.

Requires Firekylin 2.17.1+. Site title, description and navigation use core settings; footer text/author are configurable. Homepage is a paginated blog feed rather than a fixed Hugo photo/gallery landing page. Native archive, taxonomy, GET search, article/page/attachment, protected content and conditional comments are supported.

No Hugo photo gallery, image pipeline, URL-segment breadcrumbs, RSS/SEO automation, analytics or legacy IE scripts. Roboto Mono falls back to local monospace fonts; Animate.css and demo photos are not included. Cursor respects reduced motion; no JavaScript needed. Remote comment submission untested. MIT notices for the theme and Terminal CSS are included separately.

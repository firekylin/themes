# DreamCat for Firekylin
Native adaptation of DreamCat3.0.260502. Indigo232px header, overlapping78px toolbar,25/75 profile-and-post columns,12px material cards, gradient text excerpts or image cards, local clock, persistent19 primary/16 accent palettes and light/dark/system modes. Sidebar hidden below1024px. Configure profile, static saying and optional listMode=image. Native content, pagination, archives/taxonomy/search/comments/privacy; TOC and copy URL.

Original full copyright statement is accessible through a prominent appbar button; no-JavaScript footer details also works. This is a modified Firekylin version, not Typecho or author endorsement. No upstream PHP/JS executed or vendor runtime bundled. No CDN Hitokoto, QQ avatars, external fonts, donation QR, original previous/next neighbors or Typecho plugin features. No automatic license is assigned to user posts. Native page geometry shares the profile column rather than reproducing every Typecho single-page header preset. Requires Firekylin>=2.17.1.

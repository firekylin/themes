# Decent for Firekylin

Decent’s centered masthead, ruled chronological title/date list and serif article typography.

Native migration of https://github.com/jwillmer/jekyllDecent; source revision and author in NOTICE.md, original license in LICENSE. Requires Firekylin 2.17.1+. Uses native site title/description/navigation, authorName/footerText and article featuredImage. Supports posts/pages/media, archives/taxonomy, search, pagination, protected content and comments.

Upstream Sass/CSS is retained with compatibility rules for native templates. Jekyll build plugins, commercial features, external fonts/icons, demo photographs, analytics and remote widgets are excluded. Navigation wraps without JavaScript.

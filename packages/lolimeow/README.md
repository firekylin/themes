# LoliMeow for Firekylin
Native adaptation of V13.12 two-column list-one layout:80vh cover/welcome banner, soft wave separator,1320px container,40%/220px thumbnail cards, pill category labels, floating widget titles, purple accents and centered article heading. Configurable heroText/coverUrl/footerText; optional cover uses site-relative or HTTP(S) URL. Day/night/auto follows system until user selection and persists. Mobile<=991 collapses navigation/widgets and stacks cards. Source older screenshot is reference only; current V13 source determines dimensions.

Native public archive/search/category/tag data, recent5 posts, category metadata fetched only for native public list IDs, TOC, copy URL, pagination and conditional comments. No WordPress member center, favorites/likes, paid downloads, registration/email flows, live quote/image APIs, analytics, anime character assets, lazyload vendor runtime or animation preloader. Source wave motion is a static curved separator; fonts use local system fallback. No upstream PHP/JS/build executed. Requires Firekylin>=2.17.1.

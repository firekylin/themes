# Min Night for Firekylin

Min Night’s blue navigation/footer, centered introduction and compact post list, with its invert/hue-rotate night mode.

Upstream https://github.com/nathancday/min_night; pinned revision in NOTICE.md. Retains original main.css and Bootstrap 3.3.7 CSS, with Bootstrap/Normalize and original Minimal theme licenses. Native accessible button replaces jQuery/Bootstrap Toggle; persistence tolerates unavailable storage. Corrects upstream unscoped video inversion and uses a neutral background for readable inverted night colors. Night mode is manual and remembered, not driven by the operating system. Navigation wraps without JavaScript. The original introduction and blog list share the Firekylin home route; no fabricated avatar or reading-time values. Mina/VT323 use system font fallbacks; icon fonts, analytics, MathJax, related-post queries, project repository links and external comment systems are omitted.

Requires Firekylin 2.17.1+. Native posts, pages, attachments, archives, taxonomy, search, pagination, navigation, footer settings and gated comments supported. Remote Waline authentication/submission untested. Hugo shortcodes/custom feeds are not migrated.

Actual ZIP installation, 18 desktop/mobile routes and night-mode screenshots: verification/min_night. Compared source templates and CSS; no live upstream pixel-parity claim.

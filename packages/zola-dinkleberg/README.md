# Dinkleberg for Firekylin

Dinkleberg’s sticky monospace site bar, 65/35 feed/sidebar split and desktop article metadata column.

Source https://github.com/rust-br/dinkleberg; exact revision and authors in NOTICE.md, full MIT license in LICENSE. Original Sass retained and compiled with Dart Sass 1.108.0. Sidebar uses actual site navigation, not example links. On article pages metadata stays beside the reading column on desktop and stacks above it on mobile. Sticky header handles wrapped navigation without covering content. Open Sans/Source Code Pro use system fallbacks. Demo logos, organization schema placeholders, estimated reading times and manually related-post lists are omitted.

Firekylin 2.17.1+ native posts/pages/attachments, archives, taxonomy, search, pagination, navigation, footer author/text and gated comments are supported. Remote Waline authentication/submission is untested. Compiled CSS and Eta are editable without a build step.

Actual ZIP installation, desktop/mobile/palette screenshots and reproducible runner: verification/zola-dinkleberg. Compared pinned upstream templates/CSS, without a live upstream-demo pixel-parity claim.

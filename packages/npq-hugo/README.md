# NPQ for Firekylin

Port of saadnpq’s GPLv3 NPQ theme with its original dark CSS, fixed200pxsidebar, blue links and bordered summary panels. This adaptation is GPL-3.0-only; the full license and corresponding Eta/CSS/JS source are included. There is no build step for the theme itself.

Native Firekylin posts/pages, attachments, archive/taxonomy/search, pagination, private content and comments are supported. Optional avatar URLs accept HTTP(S) and local absolute paths. Footer author and description are configurable. The safe local heading TOC uses h2/h3 text, preserves IDs and hides without JavaScript. Mobile uses visible wrapping navigation rather than the upstream script-controlled drawer.

Original microblog/pinned stream, contact form, Font Awesome kit, syntax highlighting and previous/next-by-section controls are not replicated. The recent list follows Firekylin pagination instead of the fixed4-item home limit. No demo avatar or external service scripts are bundled. Dark-only and system-font rendering follows upstream. Remote comment submission and live upstream pixel comparison are untested.

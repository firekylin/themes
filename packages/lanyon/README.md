# Lanyon for Firekylin

Native adaptation of Mark Otto’s Lanyon: serif reading, narrow responsive column, compact masthead, off-canvas charcoal navigation, sliding page and split pagination. Original poole.css, syntax.css and lanyon.css are retained with native integration additions. System fallback Georgia/Helvetica replace network PT fonts.

Requires Firekylin 2.17.1+. Install the ZIP in the theme market. Native title/description/navigation populate the masthead and sidebar; authorName/footerText configure attribution and footer. The navigation checkbox is keyboard focusable and works without JavaScript. Reduced-motion preference disables transitions.

Supports native home/taxonomy/author feeds, archive/categories/tags/search, article/page/attachment, pagination, protected content and conditional core comments. Homepage uses native excerpts instead of full Jekyll posts. Jekyll related-post ranking, Liquid plugins, analytics, feeds and alternate theme palettes are not included. No remote fonts or demo content. Remote comment submission is untested. Source and MIT license are in NOTICE.md and LICENSE.

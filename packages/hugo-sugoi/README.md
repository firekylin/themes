# Sugoi for Firekylin

Anupam’s MIT Hugo Sugoi adapted to native Firekylin. Retains original Normalize 3.0.2, Skeleton 2.0.4 and custom CSS, local Raleway font, charcoal header/hero, blue rounded CTA and overlapping white reading panel. Full source attribution and CSS/font notices are included. Homepage hero text/link and footer text/author are configurable; unsafe action links are omitted.

The source homepage shows six posts without pagination; this port follows Firekylin’s chronological paginated feed. Native author/date/category metadata replaces Hugo reading-time estimates and category icons. Posts/pages, search, archive/taxonomy, protected bodies, comment gating and attachment media/downloads are supported. Header navigation remains visible initially on mobile; a keyboard-operable checkbox/label toggles it without JavaScript. Unlike the upstream hidden checkbox, the control remains focusable.

Hugo shortcodes, estimated reading time, Font Awesome, category icons, analytics, contact form and Disqus are omitted. Native comments replace remote services. Footer uses a dark background for readable attribution; native article footers retain normal text color. Featured images are not added to the text-first design.

Actual ZIP verification includes 1440px, 700px and 390px pages, DOM containment, typography/table/media regressions and no-JavaScript menu/search. Screenshots inspected against upstream screenshot/layout; no live pixel-parity or remote comment submission claim.

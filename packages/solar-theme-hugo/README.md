# Solar for Firekylin

Source https://github.com/bake/solar-theme-hugo, derived from https://github.com/mattvh/solar-theme-ghost. Exact Hugo revision and licensing in NOTICE.md. GPL-2.0-or-later, including this adaptation; complete license and editable original Sass/Eta/CSS included. Prism MIT and reset attribution included separately.

Preserves the original narrow 500px reading column, left navigation, top title/description, dated summary feed and Solarized colors. Navigation becomes horizontal on small screens. `scheme` accepts dark (default), light, gray or preference (system light/dark). No remote fonts, icon font, demo logo/media or JavaScript.

Supports native posts/pages/attachments, navigation, archives/taxonomies/search/pagination and gated comments on Firekylin 2.17.1+. Site RSS and content are managed by Firekylin. Hugo template injection, build-time syntax highlighting, draft badges and custom logo are not exposed; native privacy rules hide drafts/private posts. Remote comment authentication/submission is untested.

Verification installs the actual ZIP into a SQLite site, checks 18 desktop/mobile routes, no-JavaScript navigation/search, privacy/comment gating and wide media. Screenshots compared to pinned source styles/templates, not live-demo pixel parity. Source Sass and compiled CSS can be edited directly; regenerate color variants with Sass as needed.

# Moonwalk for Firekylin

Port of Moonwalk’s current blog layout: bordered masthead, horizontal navigation, dashed dividers, 780px reading area, compact date-plus-title list, sans headings and monospace body. Original moonwalk/list/syntax SCSS compiled and retained; the native appearance control persists light/dark choice and initially follows system preference.

Requires Firekylin 2.17.1+. Native site title/description/menu and footer fields configure the blog. Supports core feeds, archive/taxonomy/search, pagination, article/page/attachment media, password protection and conditional comments. System fonts replace IBM Plex downloads. Corrects upstream automatic-theme selector nesting for no-JavaScript appearance.

This ports the blog profile, not Jekyll’s project-card portfolio collections. Soopr services, Jekyll data-driven project lists, scroll progress, link previews, code copy, GitHub alerts, footnote tooltips, social share and Liquid plugins are excluded. No demo content, remote assets or upstream runtime bundled. Remote comment submission untested. MIT license and pinned source retained.

# WP-Svbtle for Firekylin — draft

Port of the v4.1.7 frontend theme: fixed author rail at 26% width, accent-colored circular logo, compact pill navigation, date strip, full-content post stream, large type and thin article separators. Mobile stacks the author header and uses a native expandable navigation menu. Install svbtle-0.1.0.zip through Firekylin 2.16+.

Configure username subtitle, personal introduction, authorized logo URL, accent, RSS visibility, full (default)/excerpt feed and footer. Optional light/dark/auto mode is an enhancement. TOC, reading time/progress and keyboard image dialog also enhance the frontend; navigation/content work without JavaScript. Site navigation and core article/search/archive/taxonomy/comment rendering are native.

Incomplete: real Kudos voting/counts and Kudos-ranked recommendations, WordPress link-post custom fields, arbitrary WordPress sidebar widgets, WordPress next/previous entry query and historical IE support. There is no fabricated or browser-only Kudos substitute. The separate wp-svbtle admin/editor application is outside this frontend theme; Firekylin retains its own editor. No WordPress data migration, backend replacement or complete upstream parity is claimed.

# Serene for Firekylin

Source https://github.com/isunjn/serene; exact revision and author in NOTICE.md. Full MIT license and original main.scss included.

Retains the profile header/optional circular avatar, quiet blue title/date list, original light/dark colors and narrow reading typography. Native site pagination extends the original recent-posts list. Colors follow system preference until the visitor selects a mode; localStorage failure falls back safely. Without JavaScript, CSS follows system colors. A text button replaces the upstream theme icons.

Supports Firekylin 2.17.1+ posts/pages/attachments, archives, categories/tags, search, pagination, site navigation, optional profileImage/authorName/footerText and gated comments. Zola shortcodes, generated TOC, image lightbox, code-copy buttons, reactions, outdated alerts, Giscus, KaTeX/Mermaid and instant navigation are omitted. Remote Waline authentication/submission is untested. No demo images or remote font/script dependencies bundled.

Actual ZIP/SQLite desktop/mobile checks, system/manual palette persistence, screenshots, privacy/comment gating and media containment are in verification/zola-serene. Upstream comparison uses pinned CSS/templates; no live-demo pixel-parity claim. Shipped CSS/Eta is editable without a build step.

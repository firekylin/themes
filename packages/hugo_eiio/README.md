# Eiio for Firekylin

Port of LeonHe’s MIT Hugo Eiio, retaining original styles, Bootstrap3.4.1 panels, orange branding, category intro, thumbnail/list rows, gray date badges and outlined article TOC. Theme/Bootstrap/Normalize notices are retained; Glyphicons CSS is removed and no icon assets are bundled.

Native Firekylin posts/pages, attachments, archive/taxonomy/search, pagination, private content and comments are supported. FeaturedImage supplies optional safe HTTP(S)/local thumbnails; entries without images use full width. Category/tag labels and footer settings use native widgets. The heading TOC uses safe DOM text and hides without JavaScript. Desktop navbar is sticky, mobile links wrap visibly. Narrow screens stack images above summaries.

Word-count/reading-time estimates, native Hugo page-resource image processing, social icons, syntax highlighting, previous/next articles, sharing and advertising integrations are omitted. Dates use YYYY-MM-DD. The unused remote font request and all upstream runtime dependencies/demo assets are excluded. Source CSS/templates provide the visual reference; live pixel comparison and remote comment submission are untested.

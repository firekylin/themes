# Nofancy for Firekylin

Port of gizak/nofancy by Zack Guo; fixed revision in NOTICE.md. Retains original custom.css, Pure 0.6.1 grid proportions, link/date feed and article hierarchy. Theme MIT; bundled Pure CSS BSD license in LICENSES.

Firekylin 2.17.1+: posts, pages, attachments, archive/taxonomy/search, pagination, native comments gating, navigation and footer author/text configuration. The upstream text-only list intentionally does not display featured images.

Changes: mobile navigation is always visible without JavaScript; footer remains in normal flow; metadata/footer contrast is strengthened. System font fallbacks replace Google Raleway and the embedded fonts.css whose separate font license is not included upstream. No jQuery/timeago/highlight script, tracking, remote fonts, demo content or account data bundled. Dates are absolute rather than client-relative; Hugo shortcodes and series are not implemented. External Waline login/submission is not tested.

Validation and desktop/mobile screenshots: verification/nofancy. The editable upstream CSS and native Eta are the shipped source; no build toolchain required.

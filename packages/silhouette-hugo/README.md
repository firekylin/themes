# Silhouette for Firekylin

A native adaptation of Matt Button’s MIT Hugo Silhouette theme. Retains original Bootstrap 4.1.3 and theme CSS, Oswald brand type, full-width configurable hero, dotted summary headings, 30rem desktop sidebar and dark three-column footer. Source revision and bundled CSS/font licenses are recorded in NOTICE.md and res/licenses. Default Unsplash photography and favicon are not included; provide your own heroImage or use the plain dark hero.

The homepage hero is 500px desktop/250px mobile; optional article/page featured-image banners use the source responsive heights. Lists show native author/date/tags and continue-reading links. Sidebar exposes the eight latest public posts and up to ten categories/tags with native public counts; it is hidden below 1200px as upstream. The source featured-tag Top Posts shortlist is omitted. Navigation wraps visibly without JavaScript instead of collapsing behind Bootstrap’s JS menu.

Supports native posts, pages, archives, taxonomy titles, search, pagination, protected content, attachments and comment gating. Per-page Hugo metadata, custom shortcodes, social/share widgets, RSS generation, analytics and Disqus are not implemented. Native comments replace external integration. Footer text, author and introduction are configurable.

Installed ZIP tests cover real Firekylin 2.17.1 desktop/mobile routes plus hero/sidebar/metadata behavior. Screenshots are recorded; no live upstream pixel-parity or remote comment submission claim.

# ghostwriter for Firekylin

Ghostwriter’s red wordmark, centered masthead, dotted post/date rows and bold uppercase article headings.

Source https://github.com/jbub/ghostwriter, fixed revision and attribution in NOTICE.md. Original MIT license and editable CSS retained. System font fallbacks replace remote fonts; no remote font service or demo assets are bundled. Original SCSS is included for reference alongside editable shipped CSS; its original npm imports are not required at runtime. Rory Gibson’s original theme attribution and Juraj Bubniak’s Hugo port attribution are retained. AJAX navigation and third-party icon fonts are replaced by native links.

Requires Firekylin 2.17.1+. Native posts/pages/attachments, archive/taxonomy/search, pagination, navigation, footer author/text options and comment gating. Text-first feed preserves the upstream layout. No demo content, tracking or account credentials bundled. Hugo shortcodes, custom RSS generation and provider-specific comment scripts are not ported; external Waline login/submission untested. Shipped CSS and Eta need no build step.

ZIP installation, desktop/mobile screenshots and verification runner: verification/ghostwriter. No live upstream demo or pixel-parity claim.

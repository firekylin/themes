# Inkblotty for Firekylin

Ports tosi’s GPLv3 Inkblotty, based on Michael Sisk’s Inkblot. The original CSS supplies the shadowed 1366 px white page, black navigation, summary list with dates and separator lines, and 75/25 content/sidebar layout. The sidebar contains native categories, tags, ten public recent posts and an archive link. Mobile navigation uses visible links and the sidebar stacks below the content.

Native posts, pages, attachments, archives, taxonomy, search, pagination, private content and comments are supported. Footer author and text are configurable. Article headings retain Inkblotty’s red/blue rules.

WordPress Webcomic features, Hugo related-post ranking, month archive taxonomy, thumbnails, generated table of contents, share buttons, icon fonts, syntax highlighting and ads are not included. Native archive/search routes replace Hugo-specific taxonomies and indexes. No demo photos or remote services are bundled. Live upstream pixel comparison and remote comment submission are untested.

The port is GPL-3.0-only. LICENSE, original author credits and the separate MIT Normalize notice are included. Editable source is supplied with the package, with no compilation step required.

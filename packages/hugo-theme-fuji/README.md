# Fuji for Firekylin

Port of DSRKafuU/hugo-theme-fuji (formerly amzrk2), pinned in NOTICE.md. Original Sass and Primer Markdown modules retained; Apache2.0 for Fuji/adaptation and MIT for Primer/Normalize, complete notices included. Modified source files identify changes. Original Product Sans/Fira Code remote font declarations, iconfont and demo lazyload placeholders are omitted. System fonts replace remote title/code fonts; no demo media or external asset requests bundled.

Preserves pale-white/charcoal colors with blue/lavender accents, text summary feed, large header, 75/25 content/sidebar layout, right navigation/tag list, and Primer article typography. Native body content stays intact; summaries are escaped text. Mobile sidebar appears after content instead of the original JavaScript off-canvas panel, keeping navigation usable without scripts. Native CSS follows system colors; a guarded preference controller can persist an explicit choice. Disabled JavaScript leaves a hidden toggle and automatic colors.

Native Firekylin posts/pages/attachments, taxonomy, archive, search, pagination, protected content and comment gating supported. Footer author/text options escaped. Sidebar tags use native tag widget. Omitted: generated TOC, custom Hugo shortcodes, post license attribution box, APlayer/KaTeX, image zoom/lazyload, Bangumi chart, off-canvas sidebar, external comments/analytics and client-side Fuse search. Native remote comment login/submission unverified.

Verification installs actual ZIP in Firekylin2.17.1 SQLite for18desktop/mobile routes; checks native media/privacy/search/navigation, right sidebar and visible mobile links, palette preference/persistence and storage failure. Source-based visual comparison, not live upstream demo pixel matching.

# Blackburn for Firekylin

Source https://github.com/yoshiharuyamashita/blackburn, pinned revision and license in NOTICE.md. MIT theme license preserves the upstream placeholder copyright text verbatim. Original side-menu.css and blackburn.css are included as editable sources. Pure CSS1.0.0 and its layout use separate Yahoo BSD notices; local Raleway uses SIL OFL.

Preserves 150px fixed dark desktop sidebar, thin centered Raleway masthead, blue links and spacious article-summary feed. Native Firekylin posts/pages/attachments, archives/taxonomy/search, pagination and gated comments. At mobile widths the sidebar becomes a visible wrapping top menu rather than a JS offcanvas toggle. Source light canvas remains light under a dark OS preference. Fonts/CSS are local.

Upstream nested static menu configuration, Font Awesome icons/social menu, remote MathJax, highlight.js, analytics, custom script injection and IE8 layouts are omitted. Native content and code remain readable; formulas are not rendered by this theme. No external font/CDN requests or demo images. Remote comment authentication/submission not verified.

Actual ZIP/SQLite/Chromium checks cover 18 desktop/mobile routes, no-JS menu/search, privacy/comment gating, attachments/media, fixed desktop sidebar and source light palette. Screenshots compare original source design rather than live-demo pixel equality.

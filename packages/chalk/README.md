# Chalk for Firekylin

Port of Nielsen Ramon’s Chalk: 650px reading grid, large serif logo, thin rules, spacious article previews, hover arrows and uppercase metadata. Original light/dark SCSS compiled locally; palettes follow system preference instead of Jekyll’s build-time selection.

Requires Firekylin 2.17.1+. Site title/menu/description and footer author/text use native options. Native feeds, archive/taxonomy/search, pagination, article/page/attachment, protected bodies and conditional comments are supported. Navigation uses text labels instead of remote social icons and wraps on small screens.

Lato and Cormorant Garamond use upstream-declared local fallbacks; bundled font files/demo photos are excluded. No jQuery, Webpack, scroll-reveal, zoom gallery, social-share services, Disqus or Jekyll feed/SEO plugins. Core renders article content; no dependency on upstream runtime. Remote comment submission untested. MIT license and pinned source retained.

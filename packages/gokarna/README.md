# Gokarna for Firekylin

Native GPLv3 port of Gokarna’s profile/recent-post blog: centered optional circular avatar and intro, clean dated links, wide navigation, restrained reading column, red accent and persistent dark palette. Original main/dark CSS retained. Lato uses local sans-serif fallback; font binaries and social icon collections are excluded.

Requires Firekylin 2.17.1+. Avatar URL is optional; site title/description/navigation and footer fields use native options. Appearance follows system until selected, persisting user choice. Native menu wraps and remains available without JavaScript instead of requiring the original hamburger script.

Supports native paginated feeds, archive/taxonomy/search, article/page/attachment media, protected content and core comments. Hugo featured/popular weighting, custom Markdown home content, generated SEO/feeds, social SVG injection, reading-time estimates and post TOC are excluded. No demo identity/images or third-party runtime. Remote comment submission untested. GPLv3 license and pinned source attribution retained; all adaptation source is shipped.

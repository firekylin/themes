# Hook for Firekylin

Hook’s spacious recent-post link list, purple links, gray reading canvas and native light/dark palettes.

Source https://github.com/InputUsername/zola-hook; exact revision and authors in NOTICE.md, full MIT license in LICENSE. Original Sass retained and compiled with Dart Sass 1.108.0, using the upstream system fonts. Accessible text button replaces mode SVGs; session preference is preserved and storage failures are tolerated. System changes apply until a manual choice is made, and no-JS mode follows system CSS. Firekylin pages retain visible navigation rather than only a Home link; native pagination replaces the fixed latest-20 list. Zola shortcodes, Giallo highlighting and custom feeds are omitted.

Firekylin 2.17.1+ native posts/pages/attachments, archives, taxonomy, search, pagination, navigation, footer author/text and gated comments are supported. Remote Waline authentication/submission is untested. Compiled CSS and Eta are editable without a build step.

Actual ZIP installation, desktop/mobile/palette screenshots and reproducible runner: verification/zola-hook. Compared pinned upstream templates/CSS, without a live upstream-demo pixel-parity claim.

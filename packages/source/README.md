# Source for Firekylin

Native port of Ghost Foundation’s Source. Source’s original publication grid, large sans-serif card titles, excerpts and narrow article typography. Original built screen.css is retained with font-face declarations removed; source templates drive the Eta structure. Requires Firekylin 2.17.1+. Uses native site title, description, navigation, authorName and footerText.

Supports native posts/pages/attachments, archive/taxonomy/search feeds, pagination, protected content and comments. Ghost memberships, payments, newsletters, Portal, Ghost search, infinite scrolling, Koenig interactive cards and remote integrations are not ported. Native search/pagination and comments replace those services. No demo photographs, fonts, analytics, or third-party scripts are included. Local font fallbacks apply. Source-based visual comparison only; remote comment submission untested.

# Blonde for Firekylin

wamo’s MIT Hugo Blonde adapted with its original Tailwind source/generated CSS, rounded shadow cards, 1280px two-to-one content/sidebar grid, thumbnail summaries, gray header/footer and warm-gray dark palette. Featured images are URL-validated; missing images are omitted. Thumbnails are bounded rather than using arbitrary source Tailwind width classes. Optional logo, footer author and text are configurable.

Native Firekylin widgets supply five recent public posts, ten categories, twenty tags and local search. Sidebar stacks below articles under 1024px. The archive widget links to the native complete monthly directory rather than recreating Hugo archive taxonomies. Navigation wraps visibly without JavaScript. A keyboard-accessible persistent light/dark button uses system preference initially and hides when JavaScript is disabled. Posts/pages, taxonomy, pagination, protected content, native comments and attachments are supported.

Pagefind/Google search, ads, analytics, social/share icons, Hugo shortcodes, feed generation, arbitrary widget ordering and Disqus/Giscus are omitted. Post navigation links to native archive/top rather than Hugo section siblings. Native content and comment services replace generator-specific behavior. No demo image/icon/font asset is bundled.

CSS was built using @tailwindcss/cli and tailwindcss 4.1.16 with @tailwindcss/typography 0.5.19 from original assets/css/style.css, scanning upstream layouts and native Eta templates instead of hugo_stats.json. Full notices and source input are retained.

Verification includes actual installed ZIP routes at 1440/700/390px, grid containment, emphasis/table/media checks, light/dark persistence and sidebar search. Screenshots inspected against source templates/screenshot; no live upstream pixel comparison or remote comment submission claim.

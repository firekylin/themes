# Source and resource audit

[Cordobo Green Park 2 beta.10](https://github.com/fossasia/green-park-2/tree/d89b11afb712d49fc41bc3cfab85127e5818aab9), pinned d89b11afb712d49fc41bc3cfab85127e5818aab9. Author Andreas Jacob (Cordobo), upstream contributors. style.css explicitly releases CSS, XHTML and design under GPL v2 or later and requests original author credentials remain. The footer retains Cordobo/Andreas Jacob and repository links; full GPLv2 text is included. Modified for Firekylin 2026-10-28.

upstream.css derives from screen.css; URL references are removed. Background/navigation sprite effects are recreated with CSS gradients and shapes. No upstream photographs, avatars, logos, Twitter/RSS images, favicon, advertising, analytics, scripts or web fonts are redistributed. Test media is synthetic. This avoids assuming separate image rights from code licensing. Typography uses local system fonts.

header.php supplies branding, accessibility links and green navigation; index.php supplies the full-content feed, metadata bands and taxonomy footer; sidebar.php supplies subscription/about and split widget columns; single.php supplies reading structure. Dynamic values come from public Firekylin Widgets, native pagination/comment rendering. No invented statistics or placeholder social activity. Shared core fixtures/native reading helpers are reused, not a shared visual template.

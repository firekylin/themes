# Cordobo Green Park 2 for Firekylin — draft

Port of the pinned beta.10 theme. Preserves its 1000px white shell on a gray gradient, green folded navigation, pale metadata bands, full-article feed, thin right divider and split sidebar groups. Mobile stacks the sidebar and adds a native expandable menu. Install green-park-2-0.1.0.zip through Firekylin 2.16+'s theme installer.

Settings: feedStyle full (default) or excerpt; sidebarColumns 2 (default) or 1; hideSidebar true/false; aboutTitle/aboutText; heroText subtitle; footerText. Optional colorMode light/dark/auto is a new enhancement, not an original feature. Footer source attribution remains visible. Site navigation, RSS, categories, tags, recent public posts and comments use native Firekylin data.

Home, post, page, attachment, search, archives, category/tag and error templates are included. Article directory, reading time/progress, keyboard image preview and mode preference are enhancements. Content and mobile menu work with JavaScript disabled. Article HTML is rendered by the core and trusted; labels/settings are escaped.

Not implemented: WordPress ad-manager/analytics injection, Twitter feed plugin, arbitrary WordPress widget placement and plugin blocks, FeedBurner-specific integration, WordPress author/admin edit links, WordPress previous/next entry query and historical IE support. Native public navigation/recent/category/tag groups replace WordPress-specific widget slots. No content database migration or complete WordPress plugin compatibility is claimed. Full visual parity remains a review task; source/pixel differences are recorded in VISUAL.md.

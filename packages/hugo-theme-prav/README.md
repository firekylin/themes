# Prav for Firekylin

Port of Pravin Paratey’s MIT Prav. Original CSS preserves warm off-white/near-black palettes, rounded cards with soft shadows, red accents, Bitter reading text, Fira Sans Condensed navigation and a right sidebar. PureCSS3 BSD, Normalize MIT and font OFL notices are bundled.

Native Firekylin widgets support posts/pages, attachments, taxonomy, search, pagination, private content and comments. Sidebar shows site description, latest10 public posts and tags. Native lists use safe excerpts rather than full homepage articles; taxonomy/search share this card layout. The sidebar remains on directory pages as well. Original standalone image-grid archives, avatar/social SVGs, syntax highlighting and code-copy controls are not reproduced. No demo images are copied.

The original light/dark toggle is adapted to a text button and persists the choice locally; without JavaScript, the OS preference controls colors. The button stays hidden if scripts are disabled. Local fonts replace Google requests. Browsers must support CSS light-dark() as required by current upstream styles. Footer author and description are configurable. Remote comment submission and live upstream pixel comparison are untested.

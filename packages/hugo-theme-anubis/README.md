# Anubis for Firekylin

Anubis’s restrained system typography, rounded navigation surface, generous summary feed and automatic light/dark palettes.

Source https://github.com/Mitrichius/hugo-theme-anubis, fixed revision and attribution in NOTICE.md. Original MIT license and editable CSS retained. The upstream system font stack is retained. The original auto-without-switcher mode is compiled to native CSS. Manual theme persistence, webmentions, provider comments and multilingual controls are not implemented.

Requires Firekylin 2.17.1+. Native posts/pages/attachments, archive/taxonomy/search, pagination, navigation, footer author/text options and comment gating. No demo content, tracking or account credentials bundled. Hugo shortcodes and custom RSS generation are not ported; external Waline login/submission untested. Shipped CSS and Eta need no build step.

ZIP installation, desktop/mobile screenshots and verification runner: verification/hugo-theme-anubis. No live upstream demo or pixel-parity claim.

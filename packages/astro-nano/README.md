# Astro Nano for Firekylin

Astro Nano’s compact stone-colored reading column and bordered arrow-link cards with restrained typography.

Native migration of https://github.com/markhorn-dev/astro-nano; source revision and author in NOTICE.md, original license in LICENSE. Requires Firekylin 2.17.1+. Uses native site title/description/navigation, authorName/footerText and article featuredImage. Supports posts/pages/media, archives/taxonomy, search, pagination, protected content and comments.

Upstream Sass/CSS is retained with compatibility rules for native templates. Upstream build plugins, commercial features, external fonts/icons, demo photographs, analytics and remote widgets are excluded. Navigation wraps without JavaScript.

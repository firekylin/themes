# Wave for Firekylin

Podcast-oriented square-cover episode list with source date/title/excerpt typography. Native audio attachments use browser audio controls; Ghost’s site-wide playlist is excluded.

Adapted from the pinned Ghost source in NOTICE.md, retaining original CSS and feed structure. Firekylin 2.17.1+ required. Uses native site title/description/navigation, authorName/footerText and article featuredImage. Includes native posts, pages, media attachments, archive, taxonomy, search, pagination, protected content and comment integration.

Ghost memberships, paid content, newsletter delivery, Portal, analytics, recommendations and automatic featured-post queries are excluded. No remote fonts or demo photographs are redistributed. Navigation/search work without JS.

Unused upstream PhotoSwipe sprite references are disabled; no image-lightbox runtime or sprites are shipped.

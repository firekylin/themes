# Ink for Firekylin

Port of Kailash Nadh’s Ink: 800px wrapper, optional 64px avatar, site subtitle/navigation, large day-number columns, compact dated previews, purple links and black dark palette. Original main/dark CSS retained; removed Google font import, using system sans/serif fallbacks for Inter and Playfair Display.

Requires Firekylin 2.17.1+. Configure avatar optionally; title, subtitle and menu use native site settings. Native appearance button follows the system initially and persists explicit light/dark selection. Without JavaScript the light layout, menu and search remain usable.

Uses native archive/search/taxonomy/article/page/attachment routes, pagination, protected content and core comments. Hugo RSS, Feather social icons, Disqus, analytics and automatic SEO metadata are not ported. Numeric month replaces localized month dictionaries. No upstream demo photos, external fonts or runtime libraries bundled. Remote comment submission is untested. Pinned source and MIT license retained.

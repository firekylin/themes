# Researcher for Firekylin

Port of Olivier Roques’s Hugo Researcher, itself a port of Ankit Sultana’s Jekyll Researcher. Both are GPLv3; original licenses and source attribution retained. This modified Firekylin version is GPL-3.0-only. Original Sass, resolved defaults, generated CSS, local Bootstrap4.6.2 MIT CSS and unmodified Inconsolata OFL font are included. See NOTICE.md for revision, hashes and rebuild command.

Preserves750pxmonospaced column,32pxbrand,redlinks,slash-separated menus,horizontal dividers,date/title list,numbered[1]citation-style ordered lists and centered footer. Homepage uses upstream’s list layout plus site description instead of its static resume Markdown. Native posts/pages show title/date metadata for navigation; no demo resume/avatar or logo copied.

Supports native Firekylin posts/pages,attachments,archives,taxonomy,search,pagination,protected content and comments. Menus wrap without JavaScript. Footer text/author are escaped settings. The upstream theme is light-only. Optional logo/social Font Awesome/Academicons,KaTeX,analytics,custom Sass configuration and Hugo shortcodes are not implemented. Remote comment login/submission is untested.

Actual ZIP tests on pinned Firekylin2.17.1 SQLite cover18desktop/mobile routes,private/draft exclusion,comments,attachments,wide media,code,tables,and no-JS navigation/search. Additional browser assertions verify750pxgeometry,local Inconsolata,date/title lists,slash menus,ordered-list markers,redlinks and configuredfooter.

# Simple Style for Firekylin

Port of Linlin Yan’s MIT Simple Style Hugo theme, based on the same author’s MIT webpage template. Original CSS is retained, including its blue links/headings,system fonts,responsive750/970pxreading widths,date/title list,header divider,centered footer and floated200pxTOC. Both upstream MIT notices are included.

Native Firekylin posts/pages,attachments,archives,taxonomies,search,pagination,private content and comments are supported. A small local script builds a safe heading TOC from h2/h3 text; mobile stacks the TOC above the article. Without JavaScript the article remains full width. Footer author and description are configurable. The original third-party search-provider dropdown is replaced by native search; analytics,external-link icons/new-window rewriting,Hugo subtitles/permalink shortcode and custom SEO fields are not reproduced. No demo images or font assets are copied. The theme is light-only.

Actual ZIP installation on pinned Firekylin2.17.1 covers18desktop/mobile routes,private/draft exclusion,comments,attachments,media/audio visibility,code/tables,no-JS search/navigation,heading TOC,reading width,date/title rows and footer settings. Screenshots are checked against original CSS/templates,not live pixel comparison. Remote comment login/submission is untested.

# Bear Blog
A Firekylin port of Jan Raasch’s Hugo Bear Blog. MIT. Requires Firekylin >=2.17.1.

720px text column, Verdana, inline navigation, dated title lists and OS-controlled dark palette. No theme JavaScript or remote font dependency. Configure the optional plain-text homepage introduction through theme settings. Native search, pagination, archives, categories, tags and conditional comments are supported.

Hugo’s content-only landing page becomes an optional introduction followed by the native post list. Hugo-specific shortcodes, static build configuration and content front matter are not executed. Comments use Firekylin/Waline. See NOTICE.md and VISUAL-COMPARISON.md.

# Smol for Firekylin

Smol’s original monospace typography, ASCII masthead, unboxed summary feed and automatic light/dark colors.

Upstream https://github.com/colorchestra/smol; fixed revision in NOTICE.md. Original MIT license retained. Editable original CSS and native Eta templates included. No external font, script or demo asset bundled; both themes use system fonts upstream.

Requires Firekylin 2.17.1+. Supports posts/pages/attachments, taxonomy, archive, search, pagination, navigation, footer author/text configuration and native comment gating. Text-first feed preserves upstream behavior; featured image tiles are not added.

Hugo shortcodes, custom RSS generation and plugin integrations are not implemented. Native Firekylin comments replace external comment integrations; Waline remote login/submission untested. Native navigation wraps on mobile and works without JavaScript. Dark colors follow system preference.

Real ZIP installation and desktop/mobile/dark screenshots: verification/smol. No live upstream demo or pixel-parity claim.

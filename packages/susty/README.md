# Susty for Firekylin
Native adaptation of Jack Lenox's experimental minimal WordPress theme. Retains warm-white background, black top rule, broad masthead, narrow 33em reading column, responsive system-font stack, dotted highlighted links and sparse footer. The index uses native public excerpts rather than the source theme’s full-content WordPress loop, because the native listing model supplies summaries. Optional logoUrl and footerText settings; no branded demo logo bundled. Requires Firekylin >=2.17.1.

The original standalone /menu/ page becomes a CSS :target menu view in the current document, with a close link returning to the same content. No theme JavaScript, web fonts or external UI dependencies. Native search, navigation, pagination and menu work with JavaScript disabled. Native conditional comments may load their own client. Supports posts/pages/attachments/archives/taxonomies and privacy. Does not port WordPress Customizer, Jetpack, Gutenberg or WordPress comment system. No claims of 6KB transfer, Lighthouse score or carbon savings: these depend on content, core and deployment.

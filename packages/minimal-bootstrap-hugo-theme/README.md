# Minimal Bootstrap for Firekylin

Port of Zachary Betz’s MIT Minimal Bootstrap Hugo theme. Original Bootstrap4.0.0 CSS and the theme’s default inline styles are retained, with the dark navbar, 800px container, compact linked titles/date metadata and styled code/blockquote. Bootstrap’s independent MIT notice is included.

Native Firekylin posts/pages, attachments, archives, taxonomies, search, pagination, protected content and comments are supported. The homepage follows the original default title/date list (optional Hugo summaries are not enabled). Navbar height grows for wrapped links without JavaScript. Footer author and description are configurable additions. The light theme uses system fonts.

Hugo color configuration, mainSections, image processing, Mastodon embeds, cookie-consent, analytics and Bootstrap/jQuery scripts are not carried over. Dates use YYYY-MM-DD instead of Hugo’s configurable localized format. No demo assets are copied. Source CSS/templates are used for comparison; live upstream pixel comparison and remote comment submission are untested.

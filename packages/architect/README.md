# Architect for Firekylin

Native blog adaptation of the official Jekyll/GitHub Pages Architect theme by Jason Long. Blueprint masthead, textured page and right-hand biography. Original compiled SCSS, source wrapper structure and decorative image assets are retained under CC0-1.0. This adapts a general-purpose Jekyll site theme into a complete native blog; it does not claim upstream supplied a post-feed engine.

Requires Firekylin 2.17.1+. Uses title/description/menu, authorName/footerText. Adds native post/page/attachment templates, archive/taxonomy/search lists, pagination, protection and comments. Project download/repository controls are replaced with real blog links. Remote fonts, analytics, legacy-browser scripts and Jekyll runtime are excluded. Source local font fallbacks apply. Native responsive menu works without JavaScript. Actual install screenshots/report live in verification/architect. No live upstream demo parity or remote comment submission is claimed.

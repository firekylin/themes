# Ezhil for Firekylin

Source https://github.com/vividvilla/ezhil; pinned revision in NOTICE.md. Original MIT license reproduced verbatim, including its upstream copyright placeholder; repository author attribution retained. Normalize MIT, Ubuntu Font Licence/copyright notices and Raleway SIL OFL included. Fonts are unmodified local files with hashes.

Preserves light Raleway headings, Ubuntu text, compact date/title/inline-summary list, red links, responsive reading column and sticky footer. System light/dark preference applies initially; the upstream toggle logic saves reader choice under firekylin-ezhil-theme and applies it before first paint. Text toggle replaces Feather icons and is hidden without JavaScript, when CSS still follows the system.

Native Firekylin 2.17.1+ posts/pages/attachments, navigation, archive/taxonomy/search/pagination and gated comments. Hugo custom scripts, metadata cards, section filters, syntax highlighting and social icons/analytics are omitted. Core controls private/draft visibility. Remote comments login/submission untested; no demo content or remote dependencies.

Actual ZIP/SQLite verification covers 18 desktop/mobile routes, no-JS navigation/search, privacy/comments, attachments, wide media, local fonts and system/manual/persisted dark mode. Screenshots compare source templates/CSS, not live-demo pixel parity. Original CSS and editable Eta/JS included.

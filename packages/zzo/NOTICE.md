Selected unmodified upstream Sass is retained in res/source for comparison:
layout grid/header/sidebar/navigation, classic summary and biography components,
and the five color maps. These are reference sources, not a runtime Sass build.
The native CSS transcribes those layouts and palettes with responsive/accessibility
adaptations. In particular, Kimbie title/link colors are lightened for readability.

Native Eta templates, CSS adaptations, progressive palette/TOC JS and verification
are by Firekylin contributors. The small ring brand mark is CSS, not an image asset.
No upstream cat photograph, demo thumbnails, screenshot, fonts, external scripts,
icons, analytics or third-party service credentials are distributed. Fonts use
local system fallbacks. Configured avatar/featured images may make requests to
administrator-chosen external URLs. No network requests are made by theme JS.

# Kiera for Firekylin

Kiera’s serif writing column, prominent article titles, thick navigation rule and original system light/dark palettes.

Source https://github.com/funkydan2/hugo-kiera, fixed revision and attribution in NOTICE.md. Original MIT license and editable CSS retained. Documented system font fallbacks replace remote font services; third-party icons and scripts are not bundled. Optional math engines, Font Awesome social icons, language links and galleries are omitted. Original Normalize CSS and its MIT license are included.

Requires Firekylin 2.17.1+. Native posts/pages/attachments, archive/taxonomy/search, pagination, navigation, footer author/text options and comment gating. No demo content, tracking or account credentials bundled. Hugo shortcodes and custom RSS generation are not ported; external Waline login/submission untested. Shipped CSS and Eta need no build step.

ZIP installation, desktop/mobile screenshots and verification runner: verification/hugo-kiera. No live upstream demo or pixel-parity claim.

# Visual adaptation

The pinned example Solar configuration, custom.css, header_default, summary, sidebar_container and footer templates provide the visual reference. The port retains a 1140 px desktop container, gold navigation, solarized dark background, outlined reading buttons, 25% sidebar and column footer.

Optional header image is native configuration; title stays above it. Native taxonomy/recent-post widgets replace arbitrary headless content. Sidebar left/right/none and mobile stacking are supported. The local font is Source Sans 3 rather than remote Source Sans Pro. Installed Firekylin screenshots are in verification/hugo-tikva; no live upstream pixel comparison was performed.

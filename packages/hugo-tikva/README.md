# Tikva for Firekylin

Port of Ralf Geschke’s MIT Tikva using its original custom CSS and the Solar Bootswatch palette selected by its example configuration. Preserves the header/title area, optional wide image, gold navigation, article summaries with outlined reading buttons, sidebar and multi-column footer. Sidebar position can be right, left or hidden; it stacks below content on mobile.

Native posts/pages, attachments, archive/taxonomy/search, pagination, private content and comments are supported. Header image, footer text and author are configurable. Native category/recent-post panels and footer links replace Hugo headless-content widgets. The title stays above the image, and navigation remains visible without JavaScript. Source Sans 3 replaces the upstream remote Source Sans Pro with a local OFL font.

This port includes the Solar palette only: the other Bootswatch palettes, arbitrary color settings, floating image-overlay alignment, fixed navigation, nested dropdowns, HTML footer widgets, analytics, word counts and Hugo image processing are omitted. No demo photos or external services are bundled. Live upstream pixel comparison and remote comment submission are untested.

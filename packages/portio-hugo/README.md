# Portio Blog for Firekylin

Portio's actual free Hugo blog-list and blog-single templates are migrated using the original blog-related Sass, Bootstrap 4.1.1 CSS, local Poppins and Yeseva One fonts. The native blog retains its three-column image feed, rounded images and white offset floating date/title panels, breadcrumb title area, broad cover/narrow reading column and blue footer callout. This is the blog portion of the portfolio theme; portfolio/CV/service/testimonial/contact data models are not implemented.

Native Firekylin Widgets provide posts/pages/attachments, taxonomy, archive/search, pagination, password protection and comments. Password-protected covers are suppressed in all lists using explicit flags/hash and the core redacted-title marker; detail covers are also guarded. Footer author/text remain configurable. Safe public featured images are optional; image-less cards show real titles without placeholder imagery. Native table of contents is progressively built from h2/h3/h4; keyboard mobile navigation supports Escape and remains visible without JavaScript.

Differences: sticky navigation replaces fixed overlay/headroom to accommodate native menus. Card title panels use normal flow plus negative margin instead of absolute positioning to support long native titles without overlap. The original color/typography variables are applied explicitly alongside the precompiled Bootstrap CSS. Native pagination/comments replace Hugo pagination/external services. Unlicensed demo art, mask shapes, logo, hero portfolio widgets, sharing integrations and remote scripts are omitted. Original Sass source is under res/css/source (compile blog.scss with Sass). Full current/original theme MIT, Bootstrap MIT and font OFL notices are retained. No live upstream pixel-parity or external comment submission claim.

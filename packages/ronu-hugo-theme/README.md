# Ronu for Firekylin

Port of Deepak Karanth’s softwareyoga/ronu-hugo-theme, exact revision in NOTICE.md. Original theme MIT and Sakura CSS1.3.1 MIT licenses retained. Original light/Vader CSS and custom rules are in res/source and served unchanged with native integration rules appended. System fonts; no external scripts,images,fonts or trackers.

Preserves original38emreadingcolumn,large plain title/description/read-more feed,uppercase menu,1.618lineheight,off-white background and automatic near-black Vader palette. Homepage intentionally has no date cards or thumbnails, matching upstream. Native navigation remains visible and wraps without JS. Footer retains back-to-top with native archive link; configuredtext/author are escaped.

Supports native posts/pages,attachments,archives,taxonomy,search,pagination,protected content and comments. Native excerpts replace Hugo’s Description field. The original classless HTML is adapted to classed Firekylin widgets. Optional alternative dark palette,syntax highlighting,Twitter/LinkedIn/email/RSS footer controls and analytics are not implemented. Remote comment login/submission is untested.

Actual ZIP installation in pinned Firekylin2.17.1 SQLite checks18desktop/mobile routes plus no-JS navigation/search,media/attachments,longcode,private/draft exclusion and comments. Additional assertions verifydesktopcolumn,light/Vadercolor,largeheading/read-morefeed,no-JSdark and configuredfooter. Screenshots compared with pinned CSS/templates,not live demo pixels.

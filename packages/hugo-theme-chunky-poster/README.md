# Chunky Poster for Firekylin

Port of virtualcursor’s MIT Hugo Chunky Poster using its original Sass variables and theme rules: navy typography, generous hero, first article in a wide image/text row, subsequent rounded three-column cards and navy footer. Bootstrap 4.5.2 replaces 4.4.1; Open Sans, Roboto and Roboto Mono are bundled locally. License notices and original sources are included.

Optional heroImage accepts http(s) or site-absolute paths. Native featuredImage supplies article images; cards use 2:1 crops and the leading image uses 700:450. Each paginated list highlights its first article; unlike Hugo’s unbounded home list this respects Firekylin pagination. Missing images collapse gracefully. At widths below 992px cards and lead content stack. Native navigation wraps instead of using the JavaScript collapsing/fixed menu.

Native posts/pages, archive/taxonomy/search, pagination, attachments, protected bodies and comments work. Footer text/author are configurable. Hugo author profiles, multilingual switcher, related posts, image processing, syntax highlighting, share icons and Ekko Lightbox are not implemented. Native browser loading replaces custom lazy-loading JavaScript. No demo photos or remote services are bundled. No live upstream pixel comparison or external comment submission was performed.

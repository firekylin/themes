# Aether for Firekylin

Original https://github.com/josephhutch/aether, MIT Joe Hutchinson2018, pinned revision in NOTICE.md. Original editable CSS and theme-owned organic header/footer SVGs retained; Normalize8.0.1 MIT notice included. Active theme uses system fonts; unused upstream Lato/KaTeX font bundles are not redistributed.

Preserves gray canvas, organic masthead/footer, rounded horizontal desktop image cards (stacked on mobile), summary typography, paper article and drop cap. Native featuredImage options accept HTTP(S) or site-absolute URLs; missing/unsupported images use text-only cards. No demo photos/portrait copied. Native pages/posts/attachments, archives/taxonomy/search, pagination and gated comments are supported. Navigation wraps and works without JS; reduced-motion disables card transform/transition. Source palette remains light under dark OS preference.

Upstream portrait config, background texture config, Hugo image resizing/srcset, static displayinlist metadata, shortcodes, animated hamburger, generated article TOC and related-next-card are omitted. Native archives replace static next navigation. KaTeX/highlight.js and their assets are not included; formulas/code remain native content. Native summary text replaces Hugo descriptions. Remote comment authentication/submission unverified.

Actual ZIP/SQLite/Chromium18routes at desktop/mobile, private/draft filtering, comments, no-JS navigation/search, responsive native media and supported/missing/malicious featured-image fixtures verified. Screenshots compare source design, not live-demo pixel equality.

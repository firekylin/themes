# Minima for Firekylin
Classic Minima:800px content with30px outer padding,5px charcoal top rule,26px light masthead,dated24px title-only list,centered42px post heading,two-column muted footer andCSS mobile checkbox navigation. Native routes/search/taxonomy/pagination/privacy/comments. No JavaScript required by the theme. Optional author/footer text; defaults use site metadata.

Classic light skin only; no alternate skins, Jekyll feeds/plugins/Disqus/analytics or bundled FontAwesome. Firekylin comment adapter replaces upstream integrations; its remote submission is not tested. Featured images remain inside authored content instead of inserted list banners, matching default Minima. Requires Firekylin>=2.17.1.

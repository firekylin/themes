# Mini for Firekylin

Mini’s restrained profile header, date-aligned article list and narrow readable summaries.

Adapted from https://github.com/nodejh/hugo-theme-mini; source revision and author in NOTICE.md, complete upstream license in LICENSE. Requires Firekylin 2.17.1+. Uses native site title/description/navigation, authorName/footerText and article featuredImage. Includes posts/pages/media, search, archives, taxonomy, pagination, protected content and comments.

Upstream engine-specific membership, newsletter delivery, remote search/indexing, analytics, automatic related articles and share integrations are excluded. Local fallback fonts replace upstream remote fonts/icons. No demo photos are redistributed. Responsive navigation/search work without JS.

# Brave for Firekylin
Veen Zhao Brave1.2 couple journal: paired120px portraits and heart in a500px-wide50vh hero (64px/35vh on phones),650px centered title/date journal, gradient shared-time heading and portal cards. Configure both names, optional avatars/background, timezone-qualified ISO startDate, local blessingUrl and loveList JSON [{"text":"一起旅行","done":true}]. No demo identities/dates or relationship claims are supplied by default. Missing/invalid/future start date hides counter; no-JS shows configured date. Love List is read-only, maintained in theme configuration, not an interactive shared checklist. Blessing link points to an existing native page with separately enabled comments.

Native pages/posts/archives/search/taxonomy/pagination/privacy/comments, heading TOC and URL copy. Native full navigation replaces PJAX/Bootstrap/jQuery. Static curved edge replaces animated waves; heart respects reduced motion. No original shortcodes, image checklist editor, original comment backend, music, external fonts or vendor runtime. No upstream PHP/JS executed. Requires Firekylin>=2.17.1.

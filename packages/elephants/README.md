# Elephants for Firekylin

Elephants’s centered title, Ubuntu typography and two-column date/title archive table.

Source https://github.com/meibenny/elephants; exact revision and authors in NOTICE.md, full MIT license in LICENSE. Ubuntu and Ubuntu Mono Regular are bundled unmodified under the Ubuntu Font Licence, separately from theme MIT. Native pagination, wrapping navigation and search extend the original minimal theme. No demonstration images or external services are included.

Firekylin 2.17.1+ native posts/pages/attachments, archives, taxonomy, search, pagination, navigation, footer author/text and gated comments are supported. Hugo shortcodes and custom RSS are not ported. Remote Waline authentication/submission is untested. CSS and Eta are editable without a build step. This is a light theme, including when the operating system prefers dark mode.

Actual ZIP installation, desktop/mobile/system-dark screenshots and reproducible runner: verification/elephants. Compared pinned upstream templates/CSS, without a live upstream-demo pixel-parity claim.

# Detox for Firekylin

Detox’s oversized uppercase Montserrat masthead, spacious centered post headings, tracked dates and white reading canvas.

Source https://github.com/allnightgrocery/hugo-theme-blueberry-detox; exact revision and authors in NOTICE.md, full MIT license in LICENSE. Original minified main.css includes Normalize 2.1.3; its license is retained separately. Original Ghost Detox/Jordan Bowman and Hugo port attribution preserved, including the upstream Oswaldo Acauan MIT text. Unmodified variable Montserrat font is bundled under OFL. Source Sans Pro uses its original Helvetica/Arial fallback. Social icons/share popups, obsolete Google Plus, Disqus and analytics are omitted; native navigation/search/comments replace them.

Firekylin 2.17.1+ native posts/pages/attachments, archives, taxonomy, search, pagination, navigation, footer author/text and gated comments are supported. Hugo shortcodes and custom feeds are not ported. Remote Waline authentication/submission is untested. CSS and Eta are editable without a build step.

Actual ZIP installation, desktop/mobile/system-dark screenshots and reproducible runner: verification/detox. Compared pinned upstream templates/CSS, without a live upstream-demo pixel-parity claim.

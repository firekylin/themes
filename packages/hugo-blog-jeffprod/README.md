# JeffProd for Firekylin

Port of @JeffProd’s Hugo blog. Retains original blog.css, local Bulma0.7.1,Open Sans,large hero,9/3desktop columns,white main box,excerpt rows and sidebar cards. On mobile the sidebar stacks below the main column. Original MIT and dependency licenses plus local font OFL/hash are included; see NOTICE.md.

Supports native posts/pages,attachments,taxonomies,archives,search,pagination,private content and comments. Sidebar shows native tags and five recent public posts. The upstream year-taxonomy sidebar is replaced by a link to the full native archive; related-post scoring and reading-time estimates are not reproduced. Navigation wraps in normal flow instead of fixed placement. All pages use the site title/description in the hero, with article titles in the reading box. Safe optional header-image and footer settings are supported. No demo background photograph,Font Awesome,social icons or remote scripts are distributed; with no image the original Bulma info-blue palette remains.

Actual ZIP tests on pinned Firekylin2.17.1 cover18desktop/mobile routes plus sidebar placement,tag/recent widgets,hero image,font loading,footer configuration,private/draft exclusion,media,comments and no-JS search/navigation. Screenshots are compared against pinned source CSS/templates,not a live pixel baseline. Remote comment login/submission remains untested.

# hugo-dusk for Firekylin

Hugo Dusk’s dark panels, cyan identity, centered navigation and bordered summary cards.

Source https://github.com/gyorb/hugo-dusk, fixed revision and attribution in NOTICE.md. Original MIT license and editable CSS retained. The upstream system font stack is retained; no external fonts or demo assets are bundled. The default dark palette is ported. Alternate palettes, separate microblog routing and series widgets are not included.

Requires Firekylin 2.17.1+. Native posts/pages/attachments, archive/taxonomy/search, pagination, navigation, footer author/text options and comment gating. Text-first feed preserves the upstream layout. No demo content, tracking or account credentials bundled. Hugo shortcodes, custom RSS generation and provider-specific comment scripts are not ported; external Waline login/submission untested. Shipped CSS and Eta need no build step.

ZIP installation, desktop/mobile screenshots and verification runner: verification/hugo-dusk. No live upstream demo or pixel-parity claim.

# Hikari for Firekylin

Hikari’s full-width purple post rows, date/title rhythm, quiet masthead and serif article column.

Source https://github.com/waynee95/zola-theme-hikari; pinned revision and original attribution in NOTICE.md. Full MIT license retained. Preserves the author-panel interaction with keyboard-accessible controls. No demonstration avatar, IcoMoon font, remote highlighting or math engine is bundled. Open Sans/Lora use system sans-serif/Georgia fallbacks. Purple rows are darkened for readable white text. Original Jekyll attribution and Normalize license are retained.

Native posts/pages/attachments, archives, categories, tags, search, pagination, navigation, footer settings and gated comments require Firekylin 2.17.1+. Zola shortcodes and custom RSS generation are not ported; remote Waline authentication/submission is untested.

Editable Sass is in res/source/sass; compiled CSS ships ready to use. Compile its entry file with Dart Sass 1.108, then retain the appended native integration CSS. Screenshots and actual ZIP/SQLite verification: verification/zola-zola-theme-hikari. Compared pinned upstream templates/CSS, without a live upstream-demo pixel-parity claim.

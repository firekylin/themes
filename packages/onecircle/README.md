# OneCircle public reading adaptation
Requires Firekylin>=2.17.1. Preserves the pale social-feed background, white sticky header, left navigation, rounded author/update cards, optional image grid and right profile/category/recent-post cards. Configure avatarUrl/coverUrl/profileName/profileBio for the site profile. Feed avatars use author initials, not invented profile images. Post options.featuredImage gives one cover; optional options.gallery array supplies up to9 image URLs. Images open directly without a vendor lightbox. Lists use180-character native summaries. Native article/page/attachment, archive/taxonomy, search, pagination, privacy and conditional comments supported.

This is the public reading UI only. The original requires OneCircle plugin for registration, front-end publishing, following/circles, private messages, credits/payments and user profiles; none of these services are implemented. No empty composer, follower counters, likes, views, online indicators, social login or fake engagement controls. Category/recent-post cards replace circle membership/recent-reply data. No automatic recommendation feed, image extraction from hidden bodies, editor, PJAX or plugin APIs. Avatar/profile images are site-configured; not per-user account management. Light appearance only.

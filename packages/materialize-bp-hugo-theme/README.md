# Materialize-BP for Firekylin

Sebastian Pech’s MIT Materialize-BP is adapted using original main.css and Materialize 1.0.0 CSS. The theme retains the blue masthead, elevated image cards, lightweight titles, raised read-more buttons, taxonomy action bars and orange three-column footer. Both upstream feed variants are available: the default responsive 3/2/1-column grid and optional layoutMode=single. This is a regular CSS grid, not JavaScript masonry. Native full-page article cards preserve optional featured images.

Native posts/pages, archive/taxonomy/search, pagination, attachments, protected content and comment widgets are supported. Current-page public IDs bound category/tag relation queries. Safe HTTP(S) or root-relative featuredImage URLs are used; missing/unsafe covers are omitted. Flat navigation wraps without JavaScript, replacing Materialize’s plugin drawer. Footer text/author are configurable; source social-icon column becomes author text. Blue links/buttons are darkened and orange footer/action text uses dark colors for readability.

Hugo quote/link/audio/video archetypes, image resizing, reading-time estimates, year-grouped lists, custom arbitrary scripts/CSS, multilingual switching, social icons and Hugo feed generation are not implemented. Native article content can still include audio/video. No external fonts, icons, scripts, services or demo images are bundled. Materialize-BP shares a content structure with the author’s Bootstrap-BP but uses its own Materialize design. No live upstream pixel comparison or remote comment submission was performed.

Protected listing covers are suppressed when the core supplies a protection flag/hash or its redacted protected-title marker. This also covers core versions which retain featuredImage while removing the hash from list rows.

# Risotto for Firekylin

Native port of Joe Roe’s Risotto: Base16 dark palette, monospace typography, shell-style bracketed logo, ./ menu markers, Markdown-like headings, tinted reading panel and 15rem right biography/contents sidebar. Original CSS and default palette retained; no font or icon CDN required.

Requires Firekylin 2.17.1+. Title, description and navigation use native options; authorName configures the sidebar name and footerText the footer. A generated heading TOC occupies the article sidebar and links to real body headings; below 45rem the aside follows the article. Main article content remains readable without JavaScript.

Supports native public feeds, archives, taxonomy/search, pagination, protected content and conditional comments. Default Base16 dark palette only: extra upstream palettes, Font Awesome/Academicons social icons, Hugo RSS/OG metadata and Markdown shortcodes are excluded. System monospace replaces Fira Mono. No demo imagery or remote assets. Remote comment submission untested. MIT source attribution retained.

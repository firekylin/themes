# Hello Friend NG
MIT Firekylin port, requires >=2.17.1. Preserves full-height centered landing, prompt logo and pink cursor, dark/light control, responsive menu, dashed year-grouped archive and restrained reading column. Configure logoText, subtitle, portrait, GitHub and email. Posts are reached through the Posts link, not an unsolicited homepage feed. Native search/filter pagination, taxonomy, protected content and conditional Waline comments supported.

Hugo language routing, syntax engine, Mermaid, Git commit metadata and adjacent-post links are not implemented. Default body font falls back to local system sans-serif. Social icons become labeled text links. Native dates use numeric format. See NOTICE and visual comparison.

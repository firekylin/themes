# Simple Blog for Firekylin

10mohi6’s MIT Hugo Simple Blog port retains its original Bootstrap 4.5.0/custom CSS, large centered title, skewed pale-gray backdrop, two-column centered cards, blue-underlined category links, date/excerpt/tag rows and footer navigation. At widths below 992px cards stack. Category/tag relations are loaded only for current public result IDs. The theme uses the upstream system-font stack; its unused remote Montserrat request is omitted.

Native posts/pages, archive/taxonomy/search, pagination, attachments, protected bodies and comments are supported. Footer text/author are configurable. Native previous/next page links replace the unbounded numbered pager. Article links are ordinary title links rather than stretched links covering taxonomy controls. Navigation remains in the footer, as upstream.

Hugo shortcode processing, source-language front matter and RSS generation are not implemented. No images, analytics or external services are bundled. No live upstream pixel comparison or remote comment submission was performed.

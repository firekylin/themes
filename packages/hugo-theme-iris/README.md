# IRIS for Firekylin

Port of Shohei Ueda/peaceiris’s Hugo IRIS, revision in NOTICE.md. Original MIT Sass and specified Bulma0.9.4 source/tag retained with Bulma/Minireset MIT notices. Original systemfonts; no remoteassets or demo branding copied. Build command in NOTICE.md.

Preserves dark gradient hero,centered8/12bodycolumn,two-column darkcards,skyblue/goldlinks,optionalimages,coral heading rules and darkarticle typography. Nativehomepage uses the upstream blog-list design instead of a static portfolio. Nativeposts/pages put title/date inhero and optionalfeaturedcovers abovebody. TOC links visibleh2/h3headings with text-only labels and stays hidden withoutJS. Menus remain visible and wrap onphones.

Supports native posts/pages,attachments,archives,taxonomy,search,pagination,protected content and comments. Escaped footertext/author configurable. FeaturedImage URL validation replaces Hugo eyecatch resource resizing/WebP. Nativeexcerpt replaces Description. MathJax,Mermaid,Reveal.js slides,hotkeys,sharebuttons,randomposts,git/editbuttons,multilingualcontrols,syntaxCSS,shortcodes and analytics are not ported. Remotecommentlogin/submission untested.

ActualZIP validation on pinnedFirekylin2.17.1SQLite covers18desktop/mobile routes,private/draft exclusion,comments,wide media/attachments,longcode and no-JSnavigation/search. Extrachecks cover2/1columns,eight safephotos/missing+hostileURLs,darkcardpalette,articlehero/TOC and configuredfooter. Screenshots compared with pinnedsourceCSS/templates,not livedemo pixels.

# Shadharon for Firekylin

Port of Syed Zayyan Masud’s MIT Shadharon, using original Sass, dark gray/light palettes, monospace text, red brand, date/tag/summary cards and read-more links. Roboto Mono is local with its OFL notice. Desktop uses three columns, medium screens two, mobile one.

Native Firekylin posts/pages, attachments, archive/taxonomy/search, pagination, private content and comments are supported. Footer author and description are configurable. Dark is the default, matching upstream; a local text button switches and persists light/dark mode. Without JavaScript the switch is hidden and dark remains readable. Original gray blockquote text is corrected to the active foreground for contrast.

Zola reading-time estimates, client-side search index, syntax theme, alternate image-card template, social icons and CodePen switch assets are not replicated. Native search replaces Elasticlunr. No demo assets are bundled. Original unused IBM Plex font alias is removed in favor of the declared Roboto Mono family. Source Sass/templates are the visual reference; live pixel comparison and remote comment submission are untested.

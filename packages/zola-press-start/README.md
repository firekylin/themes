# Press Start for Firekylin

Source https://github.com/brandonhon/press-start; exact revision in NOTICE.md. Includes MIT source license, original Sass/quest.js, unmodified Press Start 2P/VT323 fonts and SIL OFL licenses with hashes.

Preserves the original procedurally drawn pixel landscape, walking sprite, scroll-driven parallax/XP HUD, parchment scroll cards and blue reading panel. Uses the upstream blog section as homepage; native navigation stays visible without JavaScript. HP is decorative and XP shows page scroll progress. The portrait/project quest homepage, construction mini-game, sound effects, Lenis smooth scrolling and CRT overlay are omitted. Reduced-motion stops walk/parallax effects; article content remains visible without JavaScript.

Supports Firekylin 2.17.1+ posts/pages/attachments, archive/taxonomy/search/pagination, navigation, authorName/footerText and gated comments. Zola volume/dispatch metadata, reading-time and custom chapter/sky settings are not exposed. Remote comment authentication/submission is untested. No demo media, remote scripts/fonts or gameplay services bundled.

Actual ZIP/SQLite verification covers 18 desktop/mobile routes, no-JavaScript search/navigation, privacy/comments, media containment and generated world/sprite/progress/back-to-top behavior. Screenshots compared to pinned source templates/Sass, not live-demo pixel parity. Shipped CSS/Eta/JS can be edited directly.

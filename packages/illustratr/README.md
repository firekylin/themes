# Illustratr for Firekylin

Native migration of Automattic’s GPL-2.0-or-later Illustratr. Although described as a portfolio theme, upstream explicitly starts in traditional blog mode; this migration preserves that real blog design: original stylesheet, uppercase oversized masthead, 1100px feature images, 840px reading column, centered ruled article titles, italic metadata and coral links. Original styles/templates and complete licenses/attribution are retained. Local OFL Source Sans 3 replaces Source Sans Pro; PT Serif and Source Code Pro are bundled.

Native posts/pages, pagination, taxonomy/search/archives, comments, protected content and attachments work through Firekylin. Public lists show escaped excerpts instead of full WordPress post bodies and date captions instead of category lists; article categories/tags remain available. Safe native featuredImage covers are hidden for protected listings. Footer text/author are configurable. Navigation/search work without JavaScript.

Portfolio custom post types/grids, WordPress post-format variants, widgets, Jetpack infinite scroll/sharing/likes, dropdown navigation, Customizer colors/header images, Genericons social menus and PHP shortcodes are not implemented. No demo photographs, unknown SVGs, remote fonts or services are bundled. No live upstream pixel comparison or remote comment submission claimed.

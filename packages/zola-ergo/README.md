# Ergo for Firekylin

Ergo’s centered red identity, bold 600px summary column, rounded reading buttons and original light/Dracula palettes.

Source https://github.com/insipx/Ergo; exact revision and authors in NOTICE.md, full MIT license in LICENSE. Original Sass compiled with Dart Sass 1.108.0; source retained in res/source. Native wrapping navigation replaces the off-canvas checkbox menu. Palette button retains the original choice of light/dark and adds resilient local persistence. A configured profile image is optional; no demo avatar is bundled. Montserrat/Raleway use system sans-serif fallbacks. Translations, shortcodes, word/read-time counts, social icons and Utterances are omitted.

Firekylin 2.17.1+ native posts/pages/attachments, archives, taxonomy, search, pagination, navigation, footer author/text and gated comments are supported. Zola shortcodes and custom feeds are not ported. Remote Waline authentication/submission is untested. Compiled CSS and Eta are editable without a build step.

Actual ZIP installation, desktop/mobile/palette screenshots and reproducible runner: verification/zola-ergo. Compared pinned upstream templates/CSS, without a live upstream-demo pixel-parity claim.

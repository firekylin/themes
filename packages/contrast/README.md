# Contrast for Firekylin
Default framed layout:gray outer background,dark header/footer,white article panels,fluidcalc(.8rem+.2vw) type,1.6lineheight,blue links,dark code boxes andautomatic systemdark appearance. Native summaries/routes/search/pagination/taxonomies/privacy/comments; no themeJS. Author/footer text configurable.

Default frame/excerpt profile only, not optional sidebar/minimal profiles. System font replacesPT Sans. No KaTeX/Jekyll feed/Disqus/Isso orFontAwesome runtime; authored math must be rendered by core/plugin. Native core comments, remote submission untested. Requires Firekylin>=2.17.1.

# Hugo Initio for Firekylin

Miguel Simoni's Hugo port of Sergey Pozhilov / GetTemplate Initio, adapted using the actual upstream blog list and single templates. Retains original Bootstrap 3.0.0 and Initio CSS, centered 8-column reading area (1080px desktop container), Alice masthead, Open Sans body, italic Georgia dates, light uppercase titles, thin bordered navigation and two-tier charcoal footer. Optional validated avatar/banner URLs and footer text/author are configurable; no default photos or avatars bundled.

The home page uses the original blog layout with 400-character native excerpts and read-more links instead of full HTML posts. Categories/tags/archives/search, pagination, posts/pages, attachments, password-protected content and native comments are supported. Lists intentionally contain no featured images. Navigation wraps visibly without JavaScript. Footer retains the original text-widget arrangement using description and native navigation.

Original business landing sections (services, recent projects, clients, downloads), social/share icons, contact details/forms, Disqus, analytics, parallax/sticky-header scripts and old IE support are omitted. Native comments replace remote services. This is the blog layout, not the portfolio homepage. Required GetTemplate credit remains visible.

Licensing is combined: MIT Hugo port, CC BY 3.0 original design, Apache-2.0 Bootstrap 3.0.0 CSS, and OFL fonts. Full texts and provenance are retained; no blanket MIT claim is made.

Validation installs the actual ZIP into Firekylin 2.17.1 and tests 27 routes at 1440/700/390px, column geometry, DOM containment, rich text/media, protected metadata/body exclusion, no-JS navigation/search and native comments/attachments. Screenshots compared with pinned source and upstream screenshot; no remote comment submission claim.

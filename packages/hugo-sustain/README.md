# Sustain for Firekylin

Sustain’s green page-edge rules, compact date/title archive rows and centered 800px Bootstrap layout.

Source https://github.com/nurlansu/hugo-sustain; pinned revision, author and original license in NOTICE.md and LICENSE. Ports the upstream blog archive, not the personal avatar landing or project portfolio. Original Bootstrap 5.0.0-beta2 CSS and MIT license are bundled. Native wrapping navigation replaces the JavaScript collapse. Source Sans Pro uses the system sans-serif fallback; Font Awesome icons are excluded.

Native posts, pages, attachments, archives, categories, tags, search, pagination, navigation and gated comments; requires Firekylin 2.17.1+. Footer author/text settings are supported. Hugo shortcodes and RSS generation are not ported. External Waline authentication/submission is untested. Editable CSS and Eta ship without a build step.

Actual ZIP install and desktop/mobile route tests: verification/hugo-sustain. No live upstream demo comparison or pixel-parity claim.

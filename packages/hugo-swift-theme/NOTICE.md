# Source and attribution

Adapted from [Swift](https://github.com/onweru/hugo-swift-theme/tree/8c9f895dbc3dea2762c24be2ac8773e8ddae3b8a) by Weru, pinned at `8c9f895dbc3dea2762c24be2ac8773e8ddae3b8a`. The complete original license is in LICENSE.

Native Firekylin Eta integration by Firekylin contributors. No demo content, remote fonts, analytics or third-party service credentials included.

Original Sass is retained under res/sass and compiled with Dart Sass. Adapted font declarations use fresh OFL font downloads: Montserrat replaces upstream Metropolis because the bundled Metropolis files lack sufficient provenance; Cookie and Volkhov preserve the original script/italic families. All three full OFL notices and download hashes/URLs are in res/licenses. No original Metropolis binaries are redistributed. Root upstream LICENSE retains its original Steve Francia and Staticman attribution verbatim.

The decorative waveform is an original static SVG generated from the upstream amplitude/wavelength parameters, replacing the sine-waves library and animation. Demo photographs, default placeholder images, crypto/social icons, service scripts, recaptcha, Staticman and third-party JavaScript are omitted. Unused icon image URLs are removed from Sass. The theme uses native Firekylin comments instead.

Sass declaration spacing and a missing border-radius colon are normalized for Dart Sass compatibility.

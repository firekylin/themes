# Swift for Firekylin

Preserves Swift’s original two-column rounded image cards, dark intro panel, orange tags, Cookie wordmark, 750px article column and automatic system dark palette. Original Sass is included and compiled. Featured images are actual safe HTTP(S)/site-relative image elements; missing or unsafe images are omitted instead of using demo photos. Native public-list tag metadata is queried only for the current page’s IDs.

The menu uses a native keyboard-accessible details drawer with Escape/outside-click dismissal and works without JavaScript. Article heading deep links are generated using safe DOM methods. The decorative intro waveform is a static SVG generated from upstream parameters, so no motion/library is needed. Default demo artwork and icons are omitted.

Montserrat (OFL) explicitly replaces Metropolis because the bundled upstream font provenance could not be confirmed; fresh OFL Cookie and Volkhov retain the other original families. This changes text metrics. Inline emphasis, list counters and filled tags/pagination use a darker orange in light mode for contrast. Native Firekylin posts/pages, protected content, archive/taxonomy/search, pagination, attachments and comment gating are supported. Footer text/author are configurable.

Hugo shortcodes, arbitrary galleries, related-post matching, custom author biographies, Staticman/reCAPTCHA, share-to-clipboard widgets, crypto donations, analytics and Hugo feeds are not implemented. Native HTML media remains usable. No live upstream pixel comparison or remote comment login/submission is claimed.

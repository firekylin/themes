# Still for Firekylin

Original Zola theme: https://github.com/wjianbo/zola-theme-still, MIT Jianbo2024. Pinned revision in NOTICE.md, original editable Sass in res/source/main.scss. System fonts only; no third-party assets or JavaScript.

Retains monochrome reading-first typography, narrow centered column, homepage introduction and ruled summary feed, automatic dark scheme, article signature/date at the end and simple return links. Native Firekylin navigation, archives/taxonomy/search, pagination, gated comments and attachments extend the original minimal page structure. Site description replaces authored Zola homepage Markdown. Signature uses configured authorName or native article author.

Zola section hierarchy/back-target inference, per-article location field, custom date formatting and generated feeds/social metadata are not implemented. Native archive links replace section ancestry. Dark inline-code contrast and mobile padding adapted; browser zoom is unrestricted. Native Markdown content is used directly; no static private content index or remote services. Remote comment authentication/submission unverified.

Verified with actual ZIP installed in Firekylin2.17.1/SQLite and Chromium desktop/mobile18routes, native media/comments/privacy, no-JS navigation/search, article signature/date order and system dark palette. Screenshots compare original source design, not live-demo pixel equality.

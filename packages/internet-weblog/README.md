# Internet Weblog for Firekylin

Internet Weblog’s left-aligned header, generous summary feed, full-width dark footer and original system light/dark semantic palette.

Source https://github.com/jnjosh/internet-weblog; exact revision and authors in NOTICE.md, full MIT license in LICENSE. Original weblog.css and all three Joshin palette styles retained. Uses the upstream system-font stack. Ports the ordinary blog post type; separate micro/photo post collections, external-link posts, Lightbox galleries, RSS section controls and footer photo queries have no native equivalent and are omitted. Category/tag pages use real Firekylin data; no fabricated author handle or demonstration assets.

Firekylin 2.17.1+ native posts/pages/attachments, archives, taxonomy, search, pagination, navigation, footer author/text and gated comments are supported. Hugo shortcodes and custom RSS are not ported. Remote Waline authentication/submission is untested. CSS and Eta are editable without a build step.

Actual ZIP installation, desktop/mobile/system-dark screenshots and reproducible runner: verification/internet-weblog. Compared pinned upstream templates/CSS, without a live upstream-demo pixel-parity claim.

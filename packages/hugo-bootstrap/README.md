# Hugo Bootstrap for Firekylin

Hugo Bootstrap’s blue application bar, rounded image cards, subtle surfaces and profile sidebar.

Native migration of https://github.com/razonyang/hugo-theme-bootstrap; source revision and author in NOTICE.md, original license in LICENSE. Requires Firekylin 2.17.1+. Uses native site title/description/navigation, authorName/footerText and article featuredImage. Supports posts/pages/media, archives/taxonomy, search, pagination, protected content and comments.

Upstream Sass/CSS is retained with compatibility rules for native templates. Upstream build plugins, commercial features, external fonts/icons, demo photographs, analytics and remote widgets are excluded. Navigation wraps without JavaScript.

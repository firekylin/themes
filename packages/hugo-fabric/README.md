# Fabric for Firekylin

Ports wd’s Hugo Fabric, descended from wd’s Hexo port and Pankaj Kumar’s MIT Octopress Fabric. Retains the original 800 px centered column, dark rounded Slackey masthead, subtitle, blue Fjalla One headings, dated entries, gray separators and framed article images. Fonts are local with their separate Apache/OFL licenses.

Native posts/pages, attachments, archives, categories/tags, search, pagination, private content and comments are supported. Footer author and description are configurable. Home entries use excerpts rather than the upstream full-post body. Mobile body text is 16 px instead of 13 px; metadata contrast is improved. Decorative video borders are removed to preserve the native media aspect ratio.

Octopress AJAX navigation, Tapir search, social icons, image-based hover effects, fancyBox, bounce animations, syntax highlighting and remote services are omitted. Native search/navigation replace their upstream counterparts. No demo photos/textures are bundled. Live upstream pixel comparison and remote comment submission are untested.

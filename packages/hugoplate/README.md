# Hugoplate for Firekylin
Native port of Zeon Studio's monochrome Hugoplate landing/blog layout. Requires Firekylin >=2.17.1. Configure introTitle, introText, optional heroImage (site-relative or HTTP(S)), and footerText. First homepage shows a centered introduction/CTA and optional illustration above a two-column article grid and taxonomy sidebar; subsequent pages retain the blog header. Articles use a wide cover, metadata, inline TOC and tag/share row. Includes persisted light/dark preference, system default, mobile disclosure navigation and copy-link enhancement.

Supports native post/page/attachment/archive/taxonomy/search/pagination, privacy and conditional comments. Uses actual site navigation and public data. No Hugo content collections/shortcodes, contact backend, language switching, Fuse search, image pipeline, Swiper testimonials, relatedness ranking or third-party social sharing. No sample customer claims, branded illustration or logo bundled. Heebo/Signika use local availability with Arial/Trebuchet fallback; exact glyphs differ. Native search and comments replace Hugo modules. No upstream software was executed.

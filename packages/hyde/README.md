# Hyde for Firekylin
18rem fixed charcoal sidebar, bottom-aligned identity/navigation,3.25rem serif name,38rem reading column,4rem vertical content padding and full-width mobile masthead. Supports original8 color classes and reverse orientation via admin text settings. Native summaries, routes,search,taxonomies,pagination,privacy and comments; no theme JavaScript.

Default layout and CSS ported from Hyde/Poole. System fonts differ from original Google-hosted Abril Fatface/PT Sans. Native summaries replace original homepage full articles; no Jekyll RSS/plugins/Pygments/related-post engine. No fake project download/version/site copyright. Core comments replace integrations, remote submission untested. Requires Firekylin>=2.17.1.

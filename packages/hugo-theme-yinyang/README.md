# Yinyang for Firekylin

Yinyang’s Bungee Shade masthead, Bree Serif reading face, year-grouped dated post rows and switchable dark palette.

Source https://github.com/joway/hugo-theme-yinyang, fixed revision in NOTICE.md. Original editable CSS and MIT license retained. Bree Serif and Bungee Shade font binaries are retained with their OFL licenses in LICENSES. Native dark toggle follows the initial system preference.

Firekylin 2.17.1+: native posts/pages/attachments, search, taxonomy, archive, pagination, comments gating, site navigation and footer author/text options. No demo images, third-party analytics or remote comment scripts bundled. Text-first index retains upstream structure. Native Eta/CSS source requires no build step.

Hugo shortcodes, custom RSS generation and multilingual navigation are not implemented. Firekylin comments replace external integrations; Waline remote login/submission untested. Yinyang gallery shortcodes/related-post widgets are not ported. No live upstream demo/pixel-parity claim. Real ZIP-installation screenshots and verification runner under verification/hugo-theme-yinyang.

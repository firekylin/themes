# Fantasy for Firekylin

Port of Xingr's Aragaki-derived Fantasy theme. Requires Firekylin 2.17.1+. Install the generated ZIP and select Fantasy.

Preserves the narrow white paper wrapper, soft shadow, left avatar/right title header, short-rule navigation, text-first excerpts, hash-prefixed headings, pale metadata and footer category area. The logoUrl setting accepts HTTP(S) or a site-absolute image path; without it, the site initial is shown instead of redistributing upstream artwork.

Uses native public Widgets, pagination, search, archive, tags/categories, page/post/attachment content and comment policy. Search opens a keyboard-friendly dialog, returning focus after Escape; without JavaScript the navigation opens the normal search page.

Differences: native public ordering replaces Typecho's raw-SQL sticky/private-post injection; no random-post query or fabricated view counters. The bottom-left area links to archive and tags. No bundled Typecho comments, jQuery, emoji or syntax-highlighter runtime. Native comment renderer remains responsible for integrations; external login/submission was not tested. No decorative vertical poem is included: that text belongs to the promotional screenshot outside the theme wrapper. See NOTICE.md and VISUAL-COMPARISON.md.

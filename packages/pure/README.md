# Pure for Firekylin

Pure’s profile/navigation sidebar, muted post summaries and clean ruled article list.

Native migration of https://github.com/cofess/hexo-theme-pure; source revision and author in NOTICE.md, original license in LICENSE. Requires Firekylin 2.17.1+. Uses native site title/description/navigation, authorName/footerText and article featuredImage. Supports posts/pages/media, archives/taxonomy, search, pagination, protected content and comments.

Upstream Sass/CSS is retained with compatibility rules for native templates. Hexo build plugins, commercial features, external fonts/icons, demo photographs, analytics and remote widgets are excluded. Navigation wraps without JavaScript.

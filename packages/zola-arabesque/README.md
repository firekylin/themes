# Arabesque for Firekylin

Port of Arabesque Labs’ MIT Zola theme and design system. Retains original CSS, local OFL fonts, geometric hero drawn by the original pattern module, Jost headings and Newsreader prose, dated lists, light/dark palettes and side contents on desktop. Contents stacks above the article on mobile. The native three-way selector persists system/light/dark preference; no-JS uses the design system’s automatic palette with visible links and an undecorated readable hero.

Native posts/pages, archives, categories/tags, search, pagination, attachments, protected bodies and comments are supported; footer text/author are configurable. Contents is a safe h2/h3 DOM list. The hero geometry is static, without draw-in animation.

This port does not implement Zola bilingual routing/translation links, shortcodes, projects, remote embeds, advanced navigation menus, full design-system widgets, copy/highlight controls or search index. The source fonts/CSS include Arabic support, but a right-to-left native site was not validated. No accessibility conformance certification, live upstream pixel comparison or remote comment submission was performed. No branding images or demo assets are included.

# Ananke for Firekylin

Native Hugo Ananke port. Black publication masthead, large lightweight title, gray canvas and padded white summary cards using original Tachyons styles. Original styles and source header/summary structures are retained; Hugo rendering is replaced with native Eta widgets. Requires Firekylin 2.17.1+ and modern CSS nesting/layers support for Zen. Uses site title/description/menu and authorName/footerText.

Supports post/page/attachment, archive/taxonomy/search, pagination, protected content and comments. Hugo shortcodes, image processing, social SVG brands, newsletters, cookie/tracking integrations, podcast and full-text client search are omitted. Uses native server search; no remote fonts or demo images. Source-based comparison only; remote comment submission untested. Original license and pinned attribution preserved.

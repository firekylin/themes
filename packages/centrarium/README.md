# Centrarium for Firekylin

Centrarium’s centered title banner, clean ruled post list, excerpt/date metadata and original Bourbon/Neat layout styles.

Migration of https://github.com/bencentra/centrarium, pinned source and attribution in NOTICE.md, original license in LICENSE. Stylesheet compiled from upstream Sass. Requires Firekylin 2.17.1+. Uses native site title/description/navigation, authorName/footerText and article featuredImage. Includes posts/pages/media, archive/taxonomy, search, pagination, protected content and comments.

Jekyll build plugins, static search/feed generation, analytics, remote fonts/icons, demo photographs and external service widgets are excluded. Native wrapping navigation replaces JS-only menu controls.

# Skeleton for Firekylin
Ports Simple Themes' Smpl Skeleton default960px blog layout: blue top border, large text masthead/tagline, gray beveled navigation,11/5-style reading/sidebar split, traditional title/date/content/utility posts, blue buttons and plain footer. Requires Firekylin>=2.17.1. Optional logoUrl/headerText and sidebarPosition=left/right. On mobile sidebar stacks below content and navigation remains an always-visible vertical list; no JavaScript required.

Native posts/pages/attachments, archives/categories/tags/search, pagination, privacy and conditional comments. Explicit post options.featuredImage supplies list thumbnail; summaries are used on home as well as archive/search rather than WordPress's full home content. Category/tag links appear on details, not fabricated list metadata. No WordPress customizer/child themes, author profile APIs, bbPress/Jigoshop, Superfish, tabs/toggle/column shortcodes or external plugin installation. Original screenshot is a custom full-width demo page; this package chooses source default right-sidebar blog, not that demo content. Header font follows options.php40px rather than screenshot bold logo artwork.

Upstream style.css declares GPLv2.0 but license.txt contains GPLv3. Both are preserved verbatim; metadata uses SEE LICENSE IN LICENSE instead of silently resolving the discrepancy. UPSTREAM-STYLE-NOTICE.txt includes original author/license declaration.

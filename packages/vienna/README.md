# Vienna for Firekylin

Vienna’s photographic masthead, centered summary feed, blue headings and quiet Bootstrap article layout.

Source https://github.com/keichi/vienna; exact revision and authors in NOTICE.md, full MIT license in LICENSE. Includes upstream customized Bootstrap 3.3.2 CSS with Bootstrap/Normalize notices. Header imagery is configurable; no upstream demo photograph, avatar, social icon font or analytics is included. Source Sans Pro falls back to the system sans-serif stack.

Firekylin 2.17.1+ native posts/pages/attachments, archives, taxonomy, search, pagination, navigation, footer author/text and gated comments are supported. Hugo shortcodes and custom RSS are not ported. Remote Waline authentication/submission is untested. CSS and Eta are editable without a build step.

Actual ZIP installation, desktop/mobile screenshots and reproducible runner: verification/vienna. Compared pinned upstream templates/CSS, without a live upstream-demo pixel-parity claim.

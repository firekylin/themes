# Monochrome for Firekylin

Monochrome’s compact archive list, subtle monochrome links, dates and original responsive reading column.

Native migration of https://github.com/kaiiiz/hugo-theme-monochrome, pinned source and author in NOTICE.md, original license in LICENSE. Firekylin 2.17.1+ required. Uses native site title/description/navigation, authorName/footerText and article featuredImage. Includes posts/pages/media, search, archive, taxonomy, pagination, protected content and comments.

Platform-specific static search indexes, analytics, RSS generation, automatic related posts, math/highlighting integrations and remote fonts are excluded. No demo photography is redistributed. Navigation/search work without JS. Native archive templates replace Hugo taxonomies.

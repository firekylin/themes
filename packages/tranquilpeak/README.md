# Tranquilpeak for Firekylin
Native adaptation of default sidebar behavior1: 500px profile/navigation panel on wide screens, 250px at1024–1279, 75px icon rail at768–1023, and 55px header with collapsible sidebar on phones. Article/page/attachment routes use clear reading with hidden sidebar and centered 750px reading area. Configure profileName/profileBio/avatarUrl/coverUrl/footerText; images accept site-relative or HTTP(S) URLs. Defaults to a dark sidebar instead of bundling an unattributed cover photograph or demo identity. Requires Firekylin >=2.17.1.

Native excerpts,140px right thumbnails (hidden below480px), serif reading text, cover image, generated inline TOC, copy URL, taxonomy/archive/search/pagination/privacy and conditional comments. No fabricated social profiles/reading metrics. Native sidebar disclosure replaces swipe animation. No Hexo tags/gallery/frontmatter interpreter, Fancybox, Algolia, analytics, Gravatar, external comment integrations or six configurable sidebar modes. Open Sans/Merriweather use local fonts with Arial/Georgia fallback. No upstream JS or build executed.

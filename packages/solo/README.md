# Solo for Firekylin

Native port of Ghost Foundation’s Solo. Personal typographic introduction followed by image cards and compact dates, using Solo’s original feed and typography.

Original compiled stylesheet and header/feed/article source structures are retained. Requires Firekylin 2.17.1+. Uses site title/description/navigation, authorName/footerText and each article’s featuredImage option. Includes native posts/pages/media attachments, search, archives, taxonomy, pagination, protected content and comments.

Ghost memberships/payments, newsletter delivery, Portal search, editor-specific cards and analytics are excluded. No dead subscription/payment UI is shipped. Fonts use local fallbacks; remote font binaries and demo photographs are excluded. Native responsive navigation works without JavaScript. Visual comparison is against pinned source, not a claim of pixel-perfect demo parity; remote comment submission untested.

Unused upstream PhotoSwipe sprite references are disabled; no image-lightbox runtime or sprites are shipped.

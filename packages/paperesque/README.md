# Paperesque for Firekylin

Source https://github.com/capnfabs/paperesque, pinned in NOTICE.md; original MIT style.css and Bootstrap Reboot retained in res/source, separate MIT notices and local Lora OFL font included.

Preserves navy/coral diagonal navigation, pale desktop background, bordered/shadowed paper reading sheet, serif Lora headings, title/date rows with paper hover, side-pulled introduction at wide desktop sizes and automatic dark palette. Native Firekylin posts/pages/attachments, archive/category/tag/search, pagination and gated comments are supported. Native wrapping menu stays visible without JavaScript; mobile header is not sticky to preserve reading space. Homepage selects the native paginated post feed and description instead of Hugo section configuration.

No client JavaScript required. Upstream floating margin-footnote JS, heading-link SVGs, auto-closing menu, meta-theme-color observer, Hugo mostlyHidden frontmatter, shortcode processing, image transforms and syntax highlighting are omitted. Original prose/figure CSS remains usable with compatible stored HTML. Native footnotes stay in normal flow. No demo photos or remote font services. Remote comment authentication/submission unverified.

Actual ZIP installed into Firekylin2.17.1/SQLite, 18 Chromium desktop/mobile routes plus privacy/comments, no-JS search/navigation, attachments/media, source palette and desktop side introduction checks. Screenshots compare original source layout, not live demo pixel parity.

# Manis for Firekylin

Manis’s narrow Skeleton-derived reading column, compact dated link list and red divider accents.

Source https://github.com/yursan9/manis-hugo-theme; exact revision and authors in NOTICE.md, full MIT license in LICENSE. Retains Tulis/Skeleton and Normalize attribution. Ports the post list; work portfolio, related-post queries, translation and manual dark-mode icons are omitted. Lato/Raleway/Fira Mono use system fallbacks. Accent red is darkened for link contrast.

Firekylin 2.17.1+ native posts/pages/attachments, archives, taxonomy, search, pagination, navigation, footer author/text and gated comments are supported. Hugo shortcodes and custom RSS are not ported. Remote Waline authentication/submission is untested. CSS and Eta are editable without a build step.

Actual ZIP installation, desktop/mobile screenshots and reproducible runner: verification/manis-hugo-theme. Compared pinned upstream templates/CSS, without a live upstream-demo pixel-parity claim.

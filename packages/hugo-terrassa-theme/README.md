# Terrassa for Firekylin

Port of Daniel Zaragoza’s MIT Terrassa blog layout, with the original CSS, white shadowed navigation, amber accent/footer, centered 900px summary cards and narrow article body. The system-font stack requires no font downloads.

Native Firekylin posts/pages, attachments, archives, categories/tags, search, pagination, protected content and comments are supported. Footer author and description are configurable. Desktop header uses sticky positioning to account for wrapped navigation; mobile navigation is always visible without JavaScript. Header links and title hover use a darker amber for legibility. Lists, code and media are contained within the reading column.

The Hugo business landing page, hero/CTA, multilingual switcher, social icons and contact-service form are not included in this blog port. No demo photos, logo or undraw illustration are copied. The normal blog templates and original CSS are the visual reference; no live upstream pixel comparison or remote comment submission test is claimed.

# Landscape for Firekylin

Native port of Hexo Landscape by Tommy Chen. Original 300px banner, floating date, white article cards, gray background and right biography panel.

Original upstream stylesheet is compiled locally and retained, with native Eta markup and widget integration. Requires Firekylin 2.17.1+. Uses title, description, navigation, authorName and footerText. Includes archives, taxonomy, search, pagination, protected articles, attachment media and comments.

Demo photographs, remote fonts, social icon fonts, tracking, engine-specific shortcodes and external service integrations are excluded. No original-engine runtime is shipped. Landscape uses a solid banner rather than the upstream photograph; Clean Blog uses the no-image masthead variant; Diary uses the text-only card variant. Native responsive navigation remains usable without JavaScript. No live upstream demo comparison or remote comment submission is claimed. See NOTICE.md and LICENSE for pinned source attribution.

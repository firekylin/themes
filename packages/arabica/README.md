# Arabica for Firekylin

Arabica’s centered Lato masthead, Bree Serif article headings, optional featured images and orange-accented summaries.

Source https://github.com/nirocfz/arabica; exact revision and authors in NOTICE.md, full MIT license in LICENSE. Original screen.css and Normalize retained. Lato Light and Bree Serif Regular are bundled unmodified with separate OFL licenses and attribution. Casper table-style attribution/license retained. Orange and gray text are darkened for readability. Source Code Pro uses system monospace fallback; icon fonts, Bigfoot popovers, social widgets and analytics are omitted.

Firekylin 2.17.1+ native posts/pages/attachments, archives, taxonomy, search, pagination, navigation, footer author/text and gated comments are supported. Hugo shortcodes and custom RSS are not ported. Remote Waline authentication/submission is untested. CSS and Eta are editable without a build step.

Actual ZIP installation, desktop/mobile/system-dark screenshots and reproducible runner: verification/arabica. Compared pinned upstream templates/CSS, without a live upstream-demo pixel-parity claim.

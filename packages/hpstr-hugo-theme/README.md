# HPSTR for Firekylin

Original design by Michael Rose (https://github.com/mmistakes/hpstr-jekyll-theme); Hugo adaptation by Durand D’souza (https://github.com/dldx/hpstr-hugo-theme), pinned in NOTICE.md. Both MIT copyrights retained. Original core Sass is compiled, with separate Normalize reset MIT notice. Unmodified local Lato regular/light/bold/italic fonts include OFL1.1 notice and hashes. FontAwesome, Magnific Popup, animated drilldown menu, animation bundle, jQuery/Modernizr/respond and demo photos are excluded.

Preserves the gray canvas, centered large Lato masthead, 800px shadowed white summary cards with full-width feature images, and white paper reading column. Native featuredImage HTTP(S)/site-absolute URLs supply card and article hero images; missing/unsupported values omit images. Native posts/pages/attachments, archives/taxonomies/search/pagination, protected content and gated comments work. Footer author/description are escaped. Navigation wraps and works without JS; palette stays light under dark OS preference.

Changes: summary feed replaces full-content index; a visible navigation bar replaces animated hierarchical menu. Native optional article/page hero uses object-fit at400px desktop/240px mobile rather than the old CSS oversized-image trick. No sitewide background/hero config, reading-time estimator, external link-post front matter, image credit/caption metadata, gallery lightbox, share counters, related posts, Disqus or Hugo-specific social SEO generation. Native links replace static front-matter navigation. Native code remains plain; no syntax-highlighter JS. Remote comment authentication/submission unverified.

Validated as an actual ZIP installed into Firekylin2.17.1 SQLite with18desktop/mobile routes, hidden private/draft posts, comments, no-JS search/navigation, responsive native media, eight valid images and missing/hostile image fallbacks, local fonts and footer options. Screenshots reflect the adaptation; comparison is against pinned source, not live-demo pixel equality.

# Personal Web for Firekylin

Adaptation of Baptiste Jacquemet’s MIT Personal Web Hugo theme, preserving original Sass, fixed 30% desktop/40% tablet profile sidebar, navy/white palette, 35em blog column, Montserrat headings, Raleway summaries, dashed links, right-aligned read-more links and navy footer. Local unmodified fonts retain full OFL licenses. Root LICENSE/package/theme metadata explicitly grant MIT; the contradictory README “Unlincense” line is documented in NOTICE rather than used to change licensing.

Native blog posts/pages, pagination, taxonomy, search, attachments, comments and protected posts are supported. User profile/background images are optional site-relative or HTTP(S) URLs; none are bundled. Mobile uses an always-visible compact profile/navigation instead of upstream’s script-only overlay, making search/navigation usable without JavaScript. Listing cards intentionally remain text-only as upstream; protected image metadata is never emitted there.

Portfolio projects/testimonials, technology/design taxonomies, SVG social icons, Hugo shortcodes, automatic reading-time estimates, syntax class generation and analytics are not implemented. Native categories/tags and archives replace Hugo sections; article featured images use native options. Footer text/author are configurable. No live upstream pixel comparison or remote comment submission is claimed.

# Adams for Firekylin
Native adaptation of Tokinx Adams 1.5.7: 780px reading column, spacious masthead, horizontal dot-separated navigation, full-width 48px announcement strip that sticks after scrolling, narrow article dividers, optional post thumbnails and right-edge reading tools. Article title moves into the masthead. Requires Firekylin >=2.17.1. Configure placard and footerText; uses actual native navigation and content.

Includes persisted default/sepia/night palettes and serif/sans selection, native GET search disclosure, back-to-top link, posts/pages/attachments/archive/taxonomy/pagination and conditional comments. Font/icon dependencies replaced with system fonts and text symbols. No fake likes or WordPress comment counts; no donation QR service, external quote API, InstantClick, image lightbox, AJAX comments, reader wall, WordPress Customizer, relative time or Prettify runtime. Article metadata remains above content; native comments replace WP comments. Native mobile toolbar moved to bottom right with content clearance. No upstream PHP/JS executed.

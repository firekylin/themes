# ZolaNight for Firekylin

Adapted from mxaddict’s MIT ZolaNight with original Sass, four Tokyo Night palettes, 1024px monospace reading column, cyan rules, Markdown heading prefixes, orange links and compact date/title homepage. The homepage lists Firekylin’s current page of posts with native pagination instead of truncating to five; taxonomy/search result lists use the upstream section layout with summaries. Navigation wraps and remains available without JavaScript.

Set palette to tokyonight (default), tokyostorm, tokyomoon or tokyoday. Values are allowlisted; unknown values fall back to tokyonight. This is a server-rendered configuration, not a visitor-side switch. The upstream local Hack/Source Code Pro/Menlo font stack remains; no font files or external requests are included.

Native posts/pages, taxonomy/archive/search, protected content, comments and attachments are supported. Footer text/author are configurable. Core-rendered content replaces Zola Markdown; Catppuccin syntax processing, arbitrary section hierarchies, analytics, Ko-fi integration and feed generation are not implemented. List entries omit tag badges; article tags remain native. No live upstream pixel comparison or remote comment submission is claimed.

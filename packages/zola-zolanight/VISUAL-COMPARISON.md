# Visual adaptation

The pinned base/index/page/section templates and Sass define the reference: right-aligned navigation, cyan separators, hash-prefixed blue headings, date/title list and four named palettes. Original Sass is bundled with generated CSS. Native wrapping navigation, responsive media and long-code containment are added. Installed desktop/mobile homepage/article screenshots and reproducible verification are included. No live upstream pixel comparison was performed.

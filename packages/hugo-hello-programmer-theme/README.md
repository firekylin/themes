# Hello Programmer for Firekylin

Hello Programmer’s gray page background, white article panels, teal metadata headings and cropped featured images.

Source https://github.com/lubang/hugo-hello-programmer-theme; exact revision and authors in NOTICE.md, full MIT license in LICENSE. Uses visible wrapping navigation instead of the upstream JavaScript-only mobile menu. Demo logo and title icons are replaced by text. Noto Sans KR uses system sans-serif fallback; analytics, remote highlighting, social icon fonts and project portfolio are omitted. Teal is darkened for contrast.

Firekylin 2.17.1+ native posts/pages/attachments, archives, taxonomy, search, pagination, navigation, footer author/text and gated comments are supported. Hugo shortcodes and custom RSS are not ported. Remote Waline authentication/submission is untested. CSS and Eta are editable without a build step.

Actual ZIP installation, desktop/mobile screenshots and reproducible runner: verification/hugo-hello-programmer-theme. Compared pinned upstream templates/CSS, without a live upstream-demo pixel-parity claim.

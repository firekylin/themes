# Hulga for Firekylin

Hulga’s MIT Hugo/Bulma blog design is adapted using original Bulma 1.0.2 CSS and Hulga custom rules: teal hero, boxed post summaries, tag/date/category metadata and desktop taxonomy sidebar with native public-content counts. The sidebar is hidden on mobile as upstream; category/tag navigation remains visible. A native DOM-generated article TOC replaces tocbot and stacks below content on mobile.

Native posts/pages, archive/taxonomy/search, pagination, attachments, protected content and comments are supported. System dark mode and a persistent light/dark toggle use Bulma’s data-theme palettes. Navigation wraps without JavaScript. Footer text/author are configurable; the default hero hue is retained, with darker light-mode links for readability. Current public-result IDs bound metadata lookups.

Pagefind, PWA/service worker, KaTeX, source syntax highlighting, scroll-spy, steam-deck hero, Hugo front matter and automatic feeds are not implemented. Firekylin search/comment/content services are used. No fonts, demo images, icons or external service code are bundled. No live upstream pixel comparison or remote comment submission is claimed.

# Slim for Firekylin

Port of zhe/hugo-theme-slim by Zhe Zhang; fixed commit in NOTICE.md. Original editable slim.css, 42em column, post hierarchy, grayscale palette and vertical rhythm retained. MIT license copied verbatim, including its upstream copyright placeholder.

Requires Firekylin 2.17.1+. Native posts/pages/attachments, search, taxonomy, pagination, comment gating, site navigation and footer author/text settings. This is a text-first theme; featured thumbnails are not displayed in the original list layout.

The original JavaScript-only floating menu is replaced by visible wrapping native navigation. System fallback fonts replace remote Source Sans Pro. Hugo shortcodes, Disqus, tracking, highlight scripts and arbitrary social accounts are not included. Native Firekylin comments replace Disqus; external Waline login/submission untested. No demo content or images bundled. Editable Eta and CSS require no build step.

Screenshots and ZIP-installation evidence: verification/slim. No live upstream demo/pixel-parity claim.

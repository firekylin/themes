# Moricolor for Firekylin

Preserves the date-led journal, expandable quick previews, large site heading, green links, centered three-part pager/page menu, bottom tools, separate article heading/toolbar, pink metadata and h3/h4 directory. Original mori.css remains the theme's typography/style layer; native elements replace external Bootstrap/Flat UI JavaScript.

Requires Firekylin >=2.17.1. Install the packaged ZIP and choose Moricolor. previewCount controls initially expanded summaries (default 1), previewImages=on includes native featured images, quote supplies a static bottom sentence, textIndent=on indents article paragraphs and showComments=on opens native comments. Site navigation populates the pager menu. Preview dates are semantic disclosures and work without JavaScript. Native search, pagination, archives and taxonomy directories remain available. Article controls include home, TOC toggle, comment disclosure, clipboard link copy and keyboard image enlargement. Native Widget visibility and protected-content forms are retained.

## Differences

System fonts and Unicode/text controls replace Flat UI/icon fonts; layout primitives are independently implemented. Dates are numeric. No jQuery fades, exact zoom animation, Prism highlighting, provider-specific sharing buttons, previous/next post lookup, automatic remote Hitokoto or MoriGarden social synchronization. Typecho HTML-comment cover/excerpt directives are replaced by native featured images and public summaries. The article TOC covers h3/h4 and is desktop-only, like the original. Core comments replace Typecho comment storage/UI; remote provider authentication/submission is not verified. Colors retain the default Mori palette; original arbitrary palette/font-weight/background options are not exposed.

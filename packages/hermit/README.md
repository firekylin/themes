# Hermit for Firekylin

Native port of Track3’s Hermit: dark slate reading canvas, centered full-height spotlight, italic subtitle, fixed bottom navigation and year-grouped dashed article links. Compiles original style/predefined/syntax SCSS; native reset replaces Normalize and Animate.css is excluded. Original system font stack retained.

Requires Firekylin 2.17.1+. Title/description/navigation use core options, with authorName/footerText for the footer. The home spotlight links to the paginated feed below it; later pages and filtered archives show lists directly. Bottom navigation wraps on mobile and remains usable without JavaScript.

Supports native archive/taxonomy/GET search, pagination, article/page/attachment content, password protection and core comments. Hugo background-image immersion, photo overlays, social icons, TOC drawer, code copy, related-post ranking, RSS/analytics and Hugo shortcode services are excluded. The paginated home feed is a native addition to the upstream cover-only landing page. No demo photos/fonts/scripts bundled. Remote comment submission untested. MIT source notice retained.

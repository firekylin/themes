# Blogpaper for Firekylin

Port of Erwan Normand’s MIT Hugo Blogpaper with its original Sass and bundled normalize.css. Preserves Georgia newspaper typography,750pxcontent column,photo summaries,date/category metadata,large title banners,footer and system dark palette. Source and license details are in NOTICE.md.

Uses native Firekylin posts/pages,attachments,archives,taxonomies,search,pagination,private content and comments. Home banner and footer are settings; article/page banners and list photos use featuredImage. Safe HTTP(S) or root-relative URLs are accepted. A missing banner keeps the original plain dark fallback. Native menus wrap above the banner rather than overlaying it, keeping all links readable on narrow screens. Date is the native article subtitle; Hugo-specific subtitles,captions,parent-banner inheritance,shortcodes,custom homepage sections and full-width/wide-width classes are not implemented. No upstream demo photos or fonts are copied.

Actual ZIP installation on pinned Firekylin2.17.1 SQLite covers18desktop/mobile routes,protected content,comments,attachments,long code/tables,wide media,no-JS search/navigation,photo loading,750pxcolumn,Georgia type and light/dark colors. Visual checks use pinned upstream templates/CSS,not a live pixel comparison. Remote comment login/submission remains untested.

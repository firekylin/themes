# Paper
Firekylin port of 南小北’s Hugo Paper. MIT; Firekylin >=2.17.1.

Linen/wheat/gray/white canvas, 680px reading column, spacious title/date list, optional circular avatar/bio, mobile menu, and persistent light/dark control. Settings expose profileName, bio, avatar (HTTP(S) or absolute path), color and GitHub URL. Native search, taxonomy, archives, pagination and gated Waline comments.

Hugo-specific shortcodes, math/Mermaid, Disqus/GraphComment/Giscus and static-build SEO are not executed. Adjacent-post navigation is omitted; lists and archives provide navigation. Native dates use YYYY-MM-DD. Plain CSS reproduces the original layout without compiling upstream tools. See NOTICE and VISUAL-COMPARISON.

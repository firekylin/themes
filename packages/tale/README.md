# Tale for Firekylin

Port of Chester How’s Tale: narrow 800px/80% reading area, shaded navigation rule, serif excerpts, dated catalogue links with expanding underline, centered large article title and thick title divider. Ships compiled original upstream SCSS with native template integration. Libre Baskerville is not downloaded; its declared system Times/Palatino fallback is used.

Requires Firekylin 2.17.1+. Install the ZIP through the theme market. Uses native site title, description and navigation; authorName and footerText are optional footer settings. All routes, GET search, pagination, protected bodies and comment gating use core widgets. Navigation wraps instead of overlapping long titles on narrow screens. Catalogue hover/focus animation respects reduced motion.

Jekyll sticky post metadata, Liquid plugins, Disqus, RSS, analytics and previous/next ranking are not ported. Native summary excerpts replace Liquid content truncation. No demo assets or remote fonts bundled. Remote comment submission untested. Pinned source and MIT attribution are in NOTICE.md and LICENSE.

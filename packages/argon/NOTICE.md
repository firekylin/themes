# Source and redistribution audit

Port modified on 2026-10-28 from [solstice23/argon-theme](https://github.com/solstice23/argon-theme/tree/c88262a2dd0252d0ecd15f2a31d338fad7f19215), version 1.3.5, commit `c88262a2dd0252d0ecd15f2a31d338fad7f19215`.
Copyright solstice23 and upstream contributors. GPL-3.0-only, as declared by style.css and README; the original complete LICENSE is retained.

The upstream README requires keeping the Argon theme name and repository link in the footer. This port always displays both, alongside the upstream author's attribution. This notice does not invent additional permission.

`res/css/upstream.css` combines upstream `assets/css/argon.css` (Argon Design System v1.1.0, Copyright 2019 Creative Tim, MIT; includes Bootstrap MIT code) and `style.css` (Argon theme GPLv3). Original CSS copyright headers are preserved. Full MIT notices are in `licenses/`; the Creative Tim HTML notice was retained from the existing Bubble PR and states copyright 2020, in addition to the original 2019 notice in the CSS.

All CSS `url(...)` resources and source-map references were removed, including embedded icon/loading SVGs. No upstream fonts, photographs, avatars, stickers, logos, vendor JavaScript, Gutenberg blocks, PHP libraries or updater are redistributed. Preview landscapes and avatars are original synthetic SVGs generated by the test server. Upstream reference images are linked, not republished. Users supply their own authorized image URLs.

Templates adapt header.php, sidebar.php, index.php, template-parts/content-preview-1.php, content-single.php and page/archive structures to public Firekylin Widgets. Client interactions were rewritten without jQuery/Bootstrap JS/PJAX. firekylin.css contains platform, accessibility and responsive overrides. Original styles remain separate and auditable.

A cross-platform Hexo Argon exists; this WordPress port represents that theme family and should not be duplicated in another platform batch. Existing Bubble PR #14 shares Argon Design System ancestry but has a distinct Typecho card-grid layout; it is not this WordPress theme.

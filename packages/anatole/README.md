# Anatole for Firekylin

Original https://github.com/lxndrblz/anatole, MIT lxndrblz2020, pinned in NOTICE.md. Selected original Sass and theme-switcher source retained, fixed LTR60/40 layout values replace Hugo Sass imports. Native switcher guards storage access and respects explicit preference. Unmodified local Work Sans regular/italic variable fonts carry OFL1.1 notice/hashes. No demo avatar/photos, icon fonts, medium-zoom, animation bundle or analytics included.

Preserves fixed desktop profile sidebar, centered identity, 60% reading pane, thumbnail summaries, uppercase list titles and original white/dark-blue palettes. Sidebar moves above reading content on mobile. Optional profileImage HTTP(S)/site-absolute URL is escaped and validated; empty/unsupported values hide the image. Footer author/text options are escaped. Native featuredImage supplies thumbnails; missing/unsupported values omit them. Native posts/pages/attachments, archives/taxonomy/search/pagination, protected content and comments work. Navigation remains visible without JS. Theme toggle starts from OS preference, persists explicit light/dark selection if storage works, and retains OS following until a choice is made. Without JS, usable light palette remains and toggle is hidden.

Omitted: Hugo portfolio/contact pages, RTL layout configuration, configurable content/sidebar ratios, generated TOC, image zoom/gallery, social icon config, taxonomies in list footer, reading time, full-content index mode, multilingual menus, custom syntax highlighter and remote analytics/comments providers. Native comment login/submission unverified. Only the native date is shown in summaries; article pages retain author and tags. User avatar URL is external content if configured; none is bundled by default.

Actual ZIP installed into Firekylin2.17.1 SQLite,18routes at1440/390px, no-JS navigation/search, private/draft filtering, comments, native media, configured avatar/footer, image fallbacks and theme switch/persistence verified. Screenshots compare pinned layout/styles, not live-demo pixel equality.

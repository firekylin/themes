# Mainroad for Firekylin

Mainroad’s red-accented boxed magazine layout with thumbnail summaries and native tag sidebar.

Adapted from https://github.com/Vimux/Mainroad; source revision and author in NOTICE.md, complete upstream license in LICENSE. Requires Firekylin 2.17.1+. Uses native site title/description/navigation, authorName/footerText and article featuredImage. Includes posts/pages/media, search, archives, taxonomy, pagination, protected content and comments.

Upstream engine-specific membership, newsletter delivery, remote search/indexing, analytics, automatic related articles and share integrations are excluded. Local fallback fonts replace upstream remote fonts/icons. No demo photos are redistributed. Responsive navigation/search work without JS.

# Archer for Firekylin
Source-specific native adaptation: 50vh photographic hero, 200px profile column, 48px gutter, wide excerpt list with dashed dividers, 400px charcoal Archive/Tag/Cate drawer, large left-aligned article hero and reading progress. Configure coverUrl/avatarUrl/profileName/profileBio/footerText. Optional images use site-relative or HTTP(S) URLs; default is dark background, without an unlicensed photo or demo identity. Requires Firekylin >=2.17.1.

Native archives/tags/categories, public recent30 links, GET search, pagination, headings TOC, clipboard URL, private/draft filtering and conditional comments. Drawer columns use keyboard links and native details; without JS all drawer sections remain available. Original full-site client search, animated push/swipe, Fancybox, sharing services, Busuanzi counts, MathJax/Mermaid and upstream JS/build dependencies are not included. Oswald uses locally installed font with Arial Narrow fallback; no font binary bundled. No fabricated counts or social links.

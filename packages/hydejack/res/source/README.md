Source for the distributed stylesheet. Upstream Sass is retained (commercial pro directory excluded); main.scss resolves upstream Liquid settings to their defaults. Requires Dart Sass 1.x. Build from package directory: `sass --load-path=res/source/sass res/source/main.scss /tmp/hydejack.css --no-source-map`, then concatenate /tmp/hydejack.css and res/source/adapter.css into res/css/theme.css. Native Eta templates are the corresponding template source.

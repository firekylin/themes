# Hextra for Firekylin
Requires Firekylin>=2.17.1. Adapts Hextra landing/blog/documentation layouts:64px minimal header, large headline/blue pill CTA, three-column category cards, centered blog list,36px detail headings and right-side visible-heading TOC. Static pages add256px left navigation; blog articles retain upstream blog layout's empty left space. Native navigation and categories replace Hugo file-tree sections. Dark/light preference persists, default follows system. Configure heroTitle/heroText/heroLink/heroLabel; cards use real category counts plus archive/tag links.

Native posts/pages/attachments/search/archive/taxonomy/pagination/privacy/comments supported. Search uses server-side Firekylin; Ctrl/Cmd+K opens search page. No FlexSearch offline index/overlay, Hugo shortcodes/cards API, LaTeX/Mermaid rendering, language switching, GitHub edit links, context-menu copy/export or filesystem documentation ordering. Demo marketing claims are replaced by site content. Sidebar/TOC collapse at source-style breakpoints; mobile search opens native search. No upstream Hugo/Tailwind/JavaScript executed or bundled.

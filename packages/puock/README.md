# Puock for Firekylin — draft

Adapts Puock 2.11.0 blog layouts for Firekylin 2.16+: fixed 65px navigation, pale background, 5px-radius panels, horizontal thumbnail list or 2/3/4-column image cards, carousel, search/profile/recent/category/tag sidebar, article panel and reading controls. Install puock-0.1.0.zip through the theme installer.

Theme settings provide postStyle (card default or list), cardColumns (2/3/4), hideSidebar, announcement, optional first-three-post carousel, default thumbnail, profile name/text/avatar/cover, light/dark/auto mode, accent, intro and footer. Boolean text fields use true/false. Navigation comes from the site menu. Provide images only with your own usage rights. Footer attribution to Puock/Licoy remains visible.

Includes home/article/page/attachment/search/archive/category/tag/error templates and native comments. Keyboard image preview restores focus; heading directory, reading time/progress, desktop reading-width toggle and persistent mode switching are functional. Menu/content work without JavaScript and the carousel exposes all items in that case.

Known incomplete functionality: CMS category aggregation and enterprise/product/service layouts, configurable promotional banners rather than first-three-post carousel, custom WordPress widget ordering, PJAX/load-more, user center/OAuth/captcha, SMTP/security/backend controls, AI chat/image generation, commerce/download/login-restricted shortcodes, views/likes/rewards/posters, reader wall/books/moments and third-party player integrations. WordPress data and plugin-specific comments are not migrated. This draft is the blog-layout subset, not a completed full-feature port; these gaps require review and further implementation.

# Erblog for Firekylin

Source https://github.com/ertuil/erblog; pinned revision in NOTICE.md. MIT source, original CSS, matching Layui 2.5.5 MIT and GitHub Markdown CSS MIT notices included. System fonts; no demo portraits, unDraw artwork, Font Awesome or icon fonts.

Preserves the dark cyan top bar, two-column profile/biography introduction, teal quote-style recent articles, red taxonomy badges and white article panel. Native navigation always wraps visibly on mobile. `profileImage` accepts an http(s) or site-absolute URL; `biography` is escaped plain text. Native category/tag widgets populate the homepage sidebar.

Native Firekylin 2.17.1+ posts/pages/attachments, archive/taxonomy/search/pagination and gated comments. Native server search replaces optional Google search. Gallery/zone layouts, remote math/analytics, author social icons, custom notices, badges/color configuration and related-post services are omitted. Core controls private/draft visibility. No external runtime dependencies; remote comments submission untested.

Actual ZIP/SQLite verification covers 18 desktop/mobile routes, no-JS navigation/search, privacy/comments, attachments, wide media, profile and native taxonomy sidebar. Screenshots compare pinned source styles/templates, not live-demo pixel parity. Original CSS and editable Eta included; integration grid replaces Layui JS-driven navigation.

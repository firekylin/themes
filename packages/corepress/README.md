# CorePress adaptation
Requires Firekylin>=2.17.1. Ports the default right-sidebar blog layout: white fixed/sticky header, pale gray background, contiguous thumbnail/summary list, sidebar search and widgets, centered article title, blue heading accents and THE END marker. Configure optional logoUrl/bannerUrl/bannerLink/bannerTitle; banner is one static linked image, not a carousel. Post options.featuredImage is the explicit thumbnail. Native article/page/attachment, archive/taxonomy, search, pagination, privacy and conditional comments supported.

No WordPress editor/shortcodes, front-end user center, password-reset service, SMTP configuration, anti-copy/browser blocking, ad injection, social share/QR/rewards, view counters or automatic thumbnail extraction. Recent native posts replace latest-comment widgets. List category overlays and author avatars are omitted; categories remain available on detail pages. TOC is placed in the right sidebar rather than floating outside the reading column; hidden when sidebar is absent on mobile. Site title replaces demo logo. Bottom CorePress Theme/applek attribution always remains visible, including mobile.

# Papaya for Firekylin

Papaya’s Norican script masthead, Bootstrap reading column, thin navigation rule and clean post summaries.

Source https://github.com/plopcas/papaya, fixed revision and attribution in NOTICE.md. Original MIT license and editable CSS retained. Original Norican font included with OFL license. Original Bootstrap 4.4.1 CSS included with MIT license. The original landing masthead and original blog-list layout are combined on the Firekylin index. Feather icon scripts, analytics and social-share account integrations are not included.

Requires Firekylin 2.17.1+. Native posts/pages/attachments, archive/taxonomy/search, pagination, navigation, footer author/text options and comment gating. Text-first feed preserves the upstream layout. No demo content, tracking or account credentials bundled. Hugo shortcodes, custom RSS generation and provider-specific comment scripts are not ported; external Waline login/submission untested. Shipped CSS and Eta need no build step.

ZIP installation, desktop/mobile screenshots and verification runner: verification/papaya. No live upstream demo or pixel-parity claim.

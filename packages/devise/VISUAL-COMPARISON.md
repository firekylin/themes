# Visual adaptation

The pinned header/category-posts templates and override.scss provide the reference: 650 px light-gray layout, optional circular portrait, centered title/subtitle, dark category labels, dated links and a gradient rule. Desktop lists retain their left inset and mobile lists stack dates above titles.

Native pagination scopes category groups to the current page and first category. All remote icon/analytics/demo assets are omitted. Installed Firekylin screenshots are in verification/devise; no live upstream pixel comparison was performed.

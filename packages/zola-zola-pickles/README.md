# Zola Pickles for Firekylin

Zola Pickles’s 720px column, Selenized White palette, italic dates, Atkinson Hyperlegible body text and understated summary buttons.

Source https://github.com/lukehsiao/zola-pickles; exact revision and authors in NOTICE.md, full BlueOak-1.0.0 license in LICENSE. Retains original Sass, compiled with Dart Sass 1.108.0. Theme remains BlueOak-1.0.0; Hugo Pickles MIT ancestor, Normalize, Selenized palette license and unmodified Atkinson Hyperlegible OFL font notices are separate. Source Sans Pro uses system fallback. Native search replaces Pagefind; Font Awesome, KaTeX, webrings, instant-page prefetch and generated TOC are omitted.

Firekylin 2.17.1+ native posts/pages/attachments, archives, taxonomy, search, pagination, navigation, footer author/text and gated comments are supported. Zola shortcodes and custom feeds are not ported. Remote Waline authentication/submission is untested. Compiled CSS and Eta are editable without a build step.

Actual ZIP installation, desktop/mobile/palette screenshots and reproducible runner: verification/zola-zola-pickles. Compared pinned upstream templates/CSS, without a live upstream-demo pixel-parity claim.

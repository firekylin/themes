# Congo
Firekylin port of James Panther’s Congo. MIT; Firekylin >=2.17.1.

Centered profile or left-aligned page introduction, violet accents, compact article links with optional native featuredImage, responsive basic navigation, light/dark persistence and article directory. Configure name, bio, avatar, intro, homeLayout=profile/page and optional GitHub URL. Native archives, taxonomy, search and conditional Waline comments.

Hugo shortcode/chart/math engines, translated routing, static search index, remote image processing, word-count estimates and adjacent-post navigation are not implemented. Search navigates to the native search form; no fake static search overlay. No third-party comment provider login/submission verified.

# Nederburg for Firekylin

GPL-2.0-or-later port of https://github.com/appernetic/hugo-nederburg-theme, itself a Tracks/Compete Themes adaptation. Exact revision and attribution in NOTICE.md; original license text and corresponding editable CSS/Eta sources are included. Raleway is bundled unmodified with its OFL.

Preserves dark site chrome, alternating cover/text panels, centered uppercase headings and white article pages. Posts without a safe featuredImage use the original full-width text fallback. Covers use native img elements rather than background-image lazy-load JavaScript. Native wrapping navigation replaces the icon menu; genuine site data replaces hardcoded categories/writers. Summary excerpts follow Firekylin, not full upstream Hugo summaries.

Supports Firekylin 2.17.1+ posts/pages/attachments, archive/taxonomy/search/pagination, optional footer author/text and gated comments. Upstream multi-writer configuration, portfolios/contact forms, Gravatar, social widgets, analytics and Disqus are not ported. Remote Waline authentication/submission is untested. No upstream demonstration photographs or trademark icon sets are bundled.

Verification includes actual ZIP installation, desktop/mobile routes and screenshots, image/no-image panels, native media containment, no-JavaScript search, privacy and comments. Compare against pinned templates/CSS; no live-demo pixel-parity claim. Shipped CSS/Eta can be edited directly without a build toolchain.

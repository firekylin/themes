# Visual adaptation

Pinned blog.html, page.html, modes/_blog.scss and its pattern/token dependencies are the reference. Preserves Geist typography, Catppuccin colors, 830px width, ruled heading, excerpt rows and native tag chips. Original Sass source is bundled; only blog-related entrypoints are compiled. Native text navigation and three-way select replace icons. Collapsible h2/h3 contents replaces the Zola tree.

Installed screenshots and reproducible checks are in verification/zola-tanuki. This is blog mode, not documentation/book mode; no live upstream pixel comparison was performed.

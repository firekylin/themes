# Tanuki blog mode for Firekylin

Port of raskell.io’s MIT Tanuki **blog mode** using its original Sass, 830px reading column, Geist/Geist Mono variable fonts, Catppuccin Latte/Mocha palettes, ruled blog header, article excerpts, dates and up to three tag chips. Blog lists load only tag relations for the current public result IDs, since Firekylin list rows omit those relations. Font OFL and Catppuccin MIT notices are bundled.

A native system/light/dark select persists preference and follows system changes in automatic mode. Without JavaScript the original Mocha palette remains readable, navigation remains visible and the selector/empty contents widget are hidden. Native h2/h3 contents uses safe DOM links. Archive, categories/tags, search, pagination, posts/pages, attachments, protected bodies and comments are supported; footer author/text are configurable.

Documentation/book/product modes, versioning, resizable sidebar, cross-page print/export, mascot/icons, Elasticlunr search, keyboard shortcuts, syntax highlighter and language switching are omitted. This package represents the blog mode only. No live upstream pixel comparison or remote comment submission was performed.

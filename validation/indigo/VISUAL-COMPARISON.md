# Indigo reference comparison

Fixed upstream `e4bc41a3b9404fa870899cb14b03062d72cb10c0`, 1.7.2. Reference renders the actual original EJS and Less via Hexo 7.3.0. Configuration/dependency lockfile and synthetic source content are included. Both homepage and article are captured at 1280×900 and 390×900; paired screenshots and JSON geometry are adjacent.

Reproduce: install reference-package.json with the lockfile in a separate directory, clone pinned upstream into themes/indigo, copy reference-site.yml to _config.yml and reference-theme.yml to themes/indigo/_config.yml, reference-content to source, and legacy-underscore.js to scripts. Run Hexo generate from that directory. Set `INDIGO_REFERENCE_PUBLIC=/path/to/public node scripts/compare-indigo.js` here.

Compatibility/configuration is explicit: historical templates require a Lodash `_` global absent in modern Hexo, provided by the local shim using pinned lodash 4.17.21. `cdn=false` ensures original fixed local CSS instead of an unversioned latest CDN theme. Original Waves 0.7.4 request is served from the reference's pinned local npm package. External requests are otherwise blocked. Fade classes are set to final visible state for capture. Upstream templates are not replaced with port markup. The capture script rejects missing content headers or unstyled output; earlier failed blank/unstyled attempts were discarded, not counted as passing.

Homepage card x/y/width match at desktop (280/260/960) and mobile (0/208/390). Detail card x/y/width match at desktop (280/90/960) and mobile (0/204/390). Heights differ: original fixture includes tag chips, uses Roboto font files, includes a license panel and syntax-highlight markup; port fixture contains categories and no tags, uses system fonts and omits automatic license claims. Excerpt/read-more flow was corrected to match original inline presentation. The profile background/avatars use the same synthetic SVG, with different cropping; footer and icons differ intentionally.

Original sticky TOC is disabled for the paired reference; port comparison also disables TOC. Browser checks separately exercise the native collapsible directory inside the card. The original sticky TOC/provider integrations are not claimed as implemented. README lists the full feature limits.

Local verification: 13 Node tests, including 11 theme rendering/config/escaping/pagination tests; 11 rerun with actual Firekylin Widget/comment classes pinned to a200d5887c702acb7c264776d9827f54e8389f09; 7 Python tests; actual ThemeInstaller ZIP installation; 16 page/viewport browser renders plus drawer open/close, Escape/focus return, hidden desktop menu configuration, TOC, clipboard, long titles and no-JS mobile navigation. Browser functional tests use reduced-motion preference so geometry assertions wait for no transition. Tests use synthetic records and do not exercise production DB routing or remote comment submission. CI repeats core rendering, installation and browser checks.
